31 · 进阶选修：串口、TCP、音视频与国际化

串口与 TCP 的共同点：数据流没有业务边界

QSerialPort 的 readyRead 表示有新字节，不代表一整帧。QTcpSocket 也是字节流，可能半包或多个消息合并。设计接收缓冲区，先检查协议头和长度，再提取完整帧；限制最大长度，处理无效帧和断线。串口还要统一波特率、数据位、校验位和停止位。

建议实验：为自定义文本协议使用换行符作为帧尾，在缓冲区中逐条取出完整行，保留剩余半行。下一步再实现长度前缀协议和校验。硬件串口示例依赖设备，本课程未附宣称可直接联机的硬件程序。安装模块时先查询 aqt list-qt windows desktop --modules 6.8.3 win64_msvc2022_64，按需增加 qtserialport。

音视频

Qt Multimedia 适合播放、采集与设备选择。真实运行依赖平台后端、编码器和设备权限；旧 Qt 5 视频教程的 API 不能保证适用于 Qt 6。先做播放本地文件、错误处理、停止与释放，再研究录制与同步。不要将媒体任务与 GUI 线程上的长循环混在一起。

国际化

用 tr 标记可翻译文本，Linguist 管理 ts 文件，lrelease 生成 qm，通过 QTranslator 加载。不要用字符串拼接制作完整句子，应使用占位符，给翻译调整语序的空间。支持语言切换还要响应 LanguageChange 并重新翻译已有控件。

方向选择

工业工具优先串口/TCP、日志、可靠退出；多媒体应用优先 Quick、异步状态和平台适配；数据工具优先模型、数据库和导出。每次只选一个方向做完整小项目，再扩模块。验收：写出输入、输出、失败策略和部署依赖，而不是只列 API 名称。
