16 · QString、容器、日期和字符编码

字符和字节不能混为一谈

QString 表示 Unicode 文本，QByteArray 表示字节序列。网络和文件通常传输字节，转换应明确编码：QString::fromUtf8(bytes) 与 text.toUtf8()。不要用系统默认编码碰运气。本项目源码存为 UTF-8，MSVC 使用 /utf-8。

QString::size 统计 UTF-16 代码单元数量，某些 emoji 不是一个代码单元。面向用户的“可见字符数”还涉及组合字符和字素边界。任务标题的 200 限制在课程项目中明确采用 UTF-16 单元，避免把实现声称为完整人类字符计数。

QString message = QStringLiteral("你好，%1，今天学习 %2 分钟").arg(name).arg(minutes);
bool ok = false;
int value = input.toInt(&ok);
if (!ok) { /* 反馈数字格式错误 */ }

arg 替换占位符，不能拿来替代 SQL 参数绑定。字符串到数字转换要检查 ok，不能把失败得到的零当作真实输入零。

容器和日期

QStringList 适合字符串列表；QList/QVector 用于顺序数据；QHash 适合按键查找；QMap 按键排序。Qt 6 中 QList 和 QVector 的实现关系与 Qt 5 有变化，不要依靠旧文章推断内存行为。迭代容器时插入/删除可能让迭代器失效；先收集修改，或使用明确支持删除的迭代方式。

存储时间可采用 UTC 的 ISO 8601，展示时转为本地时区。用 QDateTime 处理日期，不用“天数乘 24 小时”推算有夏令时地区的当地日历日期。练习：读取一分钟数文本、验证范围并展示当前本地时间。验收：空值、负数、中文输入有明确处理。

常用操作先分清是否修改原值

trimmed()、toLower()、split() 返回新结果；append()、clear() 改变原对象。QStringList parts = text.split(',') 只是按分隔符拆文本，不是完整 CSV 解析器，带引号和逗号的 CSV 需要专门处理。

遍历容器可先用范围 for：for (const auto &name : names) 表达只读元素。删除时不能假设原来的索引都保持稳定；反向按下标删除、使用受支持的迭代器删除或一次过滤后生成新容器，应根据数据类型选择。

QVariant 是可存多种值的容器，不代表可以省略类型校验。JSON 的 missing、null、空字符串含义可能不同；配置中的字符串 abc 转数字失败也不应悄悄当作真实 0。日期解析后检查 isValid，用户地区显示用 QLocale，持久化时采用明确约定。

正则表达式使用 QRegularExpression，先检查表达式 isValid，再匹配；不要用正则替代全部业务规则。例如姓名是否为空用 trimmed().isEmpty 就足够，复杂邮箱规则也不等于验证了邮箱真实存在。

动手：准备含中文、emoji、空白、逗号的输入，分别打印 QString.size 和 toUtf8().size，解释它们为什么不同。验收：选择协议长度上限时说清单位，展示文字和传输字节不混用。
