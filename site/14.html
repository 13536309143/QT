QMainWindow 的组成

菜单栏、工具栏、中央区域、停靠面板和状态栏各有用途。编辑器的主文本框放 centralWidget；常用命令可以同时出现在菜单与工具栏；状态栏显示当前文件、光标位置等状态。不要为同一个保存动作建立两套互不关联的处理逻辑。

QAction 表示命令，既有文字、图标和快捷键，也有启用状态。菜单和工具栏可以共享同一个 QAction。新建 QAction 时给合适父对象，在文档不可保存时禁用动作，而不是点击后再解释为什么不能用。

auto *save = menu->addAction(tr("保存"));
save->setShortcut(QKeySequence::Save);
connect(save, &QAction::triggered, this, [this] { saveFile(); });

QKeySequence::Save 使用平台常见快捷键，优于到处硬编码 Ctrl+S。菜单文本使用 tr 可为翻译做准备。在没有 Q_OBJECT 的教学类中可以使用 QStringLiteral 固定中文；真正准备多语言的窗口应采用可提取的翻译上下文。

编辑器状态机

本例关心 path_、document modified 和保存结果。打开新文件前询问旧文档，保存对话框被取消必须返回失败，这样“关闭前保存”才不会继续关窗。保存成功后才清除 modified 标记，写失败时保留它。

练习：给 04_editor 加“另存为”和状态栏字数。验收：新文件输入后关闭，选择取消应留在窗口；选择保存但取消文件对话框也应留在窗口；保存失败不能丢掉修改。不要只测试一次正常保存。

配套完整源码

在根工程构建本章目标：04_editor。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QtWidgets>
#include <QSaveFile>
class Editor : public QMainWindow {
public:
    Editor() {
        setCentralWidget(edit_); resize(760,500);
        auto *menu = menuBar()->addMenu(QStringLiteral("文件"));
        auto *open = menu->addAction(QStringLiteral("打开")); open->setShortcut(QKeySequence::Open);
        auto *save = menu->addAction(QStringLiteral("保存")); save->setShortcut(QKeySequence::Save);
        connect(open,&QAction::triggered,this,[this] {
            if(!confirm()) return;
            const QString path=QFileDialog::getOpenFileName(this,QStringLiteral("打开 UTF-8 文本"));
            if(path.isEmpty()) return;
            QFile f(path);
            if(!f.open(QIODevice::ReadOnly)) { error(f.errorString()); return; }
            const QByteArray bytes=f.readAll();
            if(f.error()!=QFileDevice::NoError) { error(f.errorString()); return; }
            edit_->setPlainText(QString::fromUtf8(bytes)); path_=path;
            edit_->document()->setModified(false); setWindowTitle(path_);
        });
        connect(save,&QAction::triggered,this,[this] { saveFile(); });
    }
protected:
    void closeEvent(QCloseEvent *event) override { if(confirm()) event->accept(); else event->ignore(); }
private:
    QTextEdit *edit_=new QTextEdit(this);
    QString path_;
    void error(const QString &message) { QMessageBox::warning(this,QStringLiteral("文件错误"),message); }
    bool saveFile() {
        QString target=path_;
        if(target.isEmpty()) target=QFileDialog::getSaveFileName(this,QStringLiteral("保存 UTF-8 文本"));
        if(target.isEmpty()) return false;
        QSaveFile f(target); const auto bytes=edit_->toPlainText().toUtf8();
        if(!f.open(QIODevice::WriteOnly) || f.write(bytes)!=bytes.size() || !f.commit()) {
            error(f.errorString()); return false;
        }
        path_=target; edit_->document()->setModified(false); setWindowTitle(path_); return true;
    }
    bool confirm() {
        if(!edit_->document()->isModified()) return true;
        const auto choice=QMessageBox::question(this,QStringLiteral("未保存"),QStringLiteral("是否保存修改？"),
            QMessageBox::Save|QMessageBox::Discard|QMessageBox::Cancel,QMessageBox::Save);
        return choice==QMessageBox::Discard || (choice==QMessageBox::Save && saveFile());
    }
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); Editor w; w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}

对话框与主窗口：参数、结果与时机

QDialog::open()

  • 参数怎样填：无参数。
  • 作用与返回结果：异步打开模态对话框，返回 void，调用者继续执行。
  • 调用时机与易错点：对话框不能是马上离开作用域的局部对象；通过 accepted/rejected 接结果。

QDialog::accept() / reject()

  • 参数怎样填：无参数。
  • 作用与返回结果：设置对话框结果并结束交互。
  • 调用时机与易错点：accept 前应完成验证；Cancel 不应已写入真实业务数据。

setAttribute(Qt::WA_DeleteOnClose)

  • 参数怎样填：属性枚举以及可选 bool。
  • 作用与返回结果：关闭后安排删除窗口。
  • 调用时机与易错点：成员观察指针可能失效；使用 QPointer 或明确复用策略。

QMainWindow::setCentralWidget(widget)

  • 参数怎样填：中央控件指针。
  • 作用与返回结果：将控件放进主窗口中心并由主窗口拥有。
  • 调用时机与易错点：不要直接对 QMainWindow setLayout，它已有自己的结构。

menuBar()->addMenu(title)

  • 参数怎样填：菜单标题。
  • 作用与返回结果：返回新建 QMenu 指针。
  • 调用时机与易错点：菜单属于界面结构，不把 SQL 或文件业务写进菜单数据中。

QMenu::addAction(text)

  • 参数怎样填：动作标题。
  • 作用与返回结果：返回 QAction 指针，常连接 triggered。
  • 调用时机与易错点：QAction 是命令模型，可由菜单和工具栏共同使用，不是 QPushButton。

QAction::setShortcut(sequence)

  • 参数怎样填：如 QKeySequence::Save。
  • 作用与返回结果：设置命令快捷键。
  • 调用时机与易错点：优先使用平台标准键序列；不要和输入控件必要编辑快捷键冲突。

QFileDialog::getOpenFileName(...) / getSaveFileName(...)

  • 参数怎样填：父窗口、标题、初始目录和过滤器等。
  • 作用与返回结果：返回选中路径 QString，取消通常返回空字符串。
  • 调用时机与易错点：选中路径不代表已经读取或保存成功；空路径不覆盖当前文档状态。

QMessageBox::question(...)

  • 参数怎样填：父窗口、标题、内容、候选按钮和默认按钮。
  • 作用与返回结果：返回用户选择的 StandardButton。
  • 调用时机与易错点：要分别处理 Save、Discard、Cancel；Save 之后还要检查真正的保存结果。

QCloseEvent::accept() / ignore()

  • 参数怎样填：无参数。
  • 作用与返回结果：允许本次关闭或保持窗口打开。
  • 调用时机与易错点：文件对话框取消或写入失败应 ignore，不能仅看用户曾按过 Save。

Ui::Form::setupUi(widget)

  • 参数怎样填：uic 生成的函数，传要安装界面的控件。
  • 作用与返回结果：创建 ui 中定义的控件、布局和属性。
  • 调用时机与易错点：不是 Qt 通用类的任意成员；不要手工编辑生成的 ui_*.h。
