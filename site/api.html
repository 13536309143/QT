本手册解释本课程实际出现的主要 Qt 接口与自定义业务接口，不是整个 Qt 所有模块的函数全集。同名函数必须结合所属类型理解；不同重载参数不同，下面按课程采用的形式解释。正文各章也嵌入了对应分组，阅读时不必先背完整手册。

怎样逐行读代码

每次看到调用先找对象的实际类型，再判断它是构造、读取、修改、排队请求还是资源提交。接着看参数的单位与所有权、返回值的失败表示，最后追踪下一步事件或信号。返回 void 不等于操作已经完成，返回 true 也不等于远端或 GPU 已经完成任务。

例如 reply = manager->get(request) 当场返回 reply；真正的结果以后通过 finished 到达。又如 window.show() 只是请求显示，必须让事件循环和平台完成绘制；f.commit() 却是必须检查成功与否的保存边界。三者不能一律理解为“调用完就全部完成”。

窗口与应用：参数、结果与时机

QApplication(argc, argv)

  • 参数怎样填：接收 main 的参数；argc 按引用传递，因此不能传临时值。
  • 作用与返回结果：创建 Widgets 应用对象，建立 GUI 所需环境；不是显示一个窗口。
  • 调用时机与易错点：一个进程通常只建一个应用对象，而且要早于 QWidget 构造，晚于窗口析构。

QWidget(parent)

  • 参数怎样填：parent 是父控件，可为 nullptr。
  • 作用与返回结果：创建控件；没有父控件时通常是顶层窗口。
  • 调用时机与易错点：父控件影响可视层级与销毁责任；构造不会自动 show。

QLabel(text, parent)

  • 参数怎样填：text 为待显示 QString；parent 为所有者。
  • 作用与返回结果：创建文本或图片展示控件，本例显示文字。
  • 调用时机与易错点：标签不负责业务数据校验；展示字符串不应作为唯一业务状态。

resize(width, height)

  • 参数怎样填：两个 int 表示控件逻辑尺寸。
  • 作用与返回结果：请求调整尺寸，返回 void；布局和尺寸约束可能影响最终大小。
  • 调用时机与易错点：不是物理像素保证，也不代表禁止用户再次缩放。

setWindowTitle(title)

  • 参数怎样填：QString 窗口标题。
  • 作用与返回结果：改变顶层窗口标题，返回 void。
  • 调用时机与易错点：子控件设置标题不一定产生可见顶层标题。

setAlignment(flags)

  • 参数怎样填：如 Qt::AlignCenter，可用按位或组合水平与垂直方向。
  • 作用与返回结果：改变 QLabel 内容对齐。
  • 调用时机与易错点：不是移动控件本身；控件位置由布局决定。

show()

  • 参数怎样填：无参数。
  • 作用与返回结果：请求显示窗口并安排平台事件；返回 void。
  • 调用时机与易错点：返回时不保证首帧已经绘制，更不代表渲染验证通过。

exec()

  • 参数怎样填：应用对象无参数版本。
  • 作用与返回结果：进入事件循环，直到 quit/exit；返回 int 退出码。
  • 调用时机与易错点：不是每次点击都调用一次，GUI 线程中的长任务会阻止循环分发事件。

arguments()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回 QStringList 命令行参数，包含程序名。
  • 调用时机与易错点：本课程用 contains("--smoke") 判断启动检查模式，不能把它当业务界面输入。

QTimer::singleShot(ms, context, functor)

  • 参数怎样填：毫秒延迟、生命周期上下文和回调。
  • 作用与返回结果：安排一次回调；返回 void。
  • 调用时机与易错点：延迟不是精密截止时间；上下文销毁后不执行该回调。

QCoreApplication::quit()

  • 参数怎样填：无参数。
  • 作用与返回结果：请求事件循环以正常退出方式结束。
  • 调用时机与易错点：不会自动中断正卡住的用户代码；重要数据仍要走保存与退出策略。

对象树与连接：参数、结果与时机

QObject::connect(sender, signal, context, functor)

  • 参数怎样填：发送者、类型安全信号指针、上下文、lambda。
  • 作用与返回结果：返回 QMetaObject::Connection；建立以后发生的通知关系。
  • 调用时机与易错点：不是调用槽一次；重复建立会重复执行。上下文只保护自己的寿命，不保护随意捕获的外部指针。

QObject::disconnect(connection)

  • 参数怎样填：传保存的连接句柄。
  • 作用与返回结果：返回 bool，表示是否成功断开。
  • 调用时机与易错点：已经排队的调用需要结合实际情况处理；用请求编号拒绝旧结果更可靠。

setObjectName(name)

  • 参数怎样填：字符串逻辑标识。
  • 作用与返回结果：为测试、样式或 findChild 提供名称；返回 void。
  • 调用时机与易错点：C++ 变量名不会自动成为 objectName，改其中一个不自动改另一个。

children()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回直接 QObject 子对象列表。
  • 调用时机与易错点：不是整个后代树；值类型 QString 不会出现在对象树中。

deleteLater()

  • 参数怎样填：无参数。
  • 作用与返回结果：投递延迟删除，返回 void。
  • 调用时机与易错点：不是立即 delete；依赖相应线程的事件处理与结束机制，调用后不再发起依赖其长期存活的新工作。

QPointer<T>(object)

  • 参数怎样填：观察一个 QObject 派生对象。
  • 作用与返回结果：对象真正销毁后观察指针清空。
  • 调用时机与易错点：不延长寿命，不提供跨线程锁；隐藏窗口不会使它清空。

moveToThread(thread)

  • 参数怎样填：目标 QThread 指针。
  • 作用与返回结果：Qt 6.8 返回 bool，成功后改变线程归属。
  • 调用时机与易错点：有 parent 的对象不能随意移动；普通函数直接调用仍在调用者线程运行。

布局与尺寸：参数、结果与时机

QVBoxLayout(parent)

  • 参数怎样填：父 QWidget 或无父布局。
  • 作用与返回结果：创建纵向排列的布局。
  • 调用时机与易错点：带 QWidget 参数时安装为该控件的顶层布局，不给同一窗口安装第二个顶层布局。

addWidget(widget, stretch)

  • 参数怎样填：控件指针和额外空间分配权重。
  • 作用与返回结果：加入布局，返回 void。
  • 调用时机与易错点：stretch 不是像素或百分比，受最小尺寸与 sizePolicy 约束。

addLayout(layout, stretch)

  • 参数怎样填：子布局与拉伸权重。
  • 作用与返回结果：组成嵌套布局。
  • 调用时机与易错点：布局不是 QWidget，不能把任意布局直接传 addWidget。

addStretch(stretch)

  • 参数怎样填：默认权重为 0，也可指定正权重。
  • 作用与返回结果：加入可伸展空白项。
  • 调用时机与易错点：用来推动控件位置，不负责存储和验证业务数据。

QFormLayout::addRow(label, field)

  • 参数怎样填：标签文本和输入控件，或单个跨行控件。
  • 作用与返回结果：创建表单行；字符串标签重载会建立合适的 buddy。
  • 调用时机与易错点：它与 QVBoxLayout::addWidget 的用途不同，要先确认当前布局类型。

setMinimumSize(w, h)

  • 参数怎样填：逻辑最小宽高。
  • 作用与返回结果：设置允许的尺寸下限。
  • 调用时机与易错点：不要用过大下限导致小屏窗口无法使用；需要长表单时考虑滚动区。

setSizePolicy(horizontal, vertical)

  • 参数怎样填：QSizePolicy 枚举或策略对象。
  • 作用与返回结果：表达控件愿意怎样缩放。
  • 调用时机与易错点：这是布局协商信息，不强制覆盖其他尺寸约束。

输入、选择与表单：参数、结果与时机

QLineEdit::text()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回当前 QString 文本副本。
  • 调用时机与易错点：读取不会自动 trimmed 或校验；空白字符串可能仍非空。

QLineEdit::setText(text)

  • 参数怎样填：新的 QString。
  • 作用与返回结果：替换输入内容，可能发出 textChanged。
  • 调用时机与易错点：程序设置不等于用户编辑，区别 textEdited；必要时防止保存动作被同步通知触发。

setPlaceholderText(text)

  • 参数怎样填：空输入时的提示文本。
  • 作用与返回结果：设置占位提示，返回 void。
  • 调用时机与易错点：不是默认值；text() 仍可能为空。

setMaxLength(length)

  • 参数怎样填：int，输入长度上限。
  • 作用与返回结果：限制 QLineEdit 文本长度。
  • 调用时机与易错点：业务层仍需验证；字符长度和 UTF-8 协议字节数不是同一单位。

QSpinBox::setRange(min, max)

  • 参数怎样填：最小与最大 int。
  • 作用与返回结果：设置合法输入区间，当前值可能随之被调整。
  • 调用时机与易错点：先设范围，再设默认值；不要用它代替仓储边界验证。

QSpinBox::value() / setValue(value)

  • 参数怎样填：读取无参数，写入 int。
  • 作用与返回结果：读取返回 int；写入返回 void，值变化时发 valueChanged。
  • 调用时机与易错点：设置与当前相同的值不持续制造变化，所以简单双向同步可终止。

QCheckBox::isChecked()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回 bool 选中状态。
  • 调用时机与易错点：三态复选框需要更细状态时读取 checkState，不能把所有状态压成同一个 bool。

QComboBox::addItem(text, data)

  • 参数怎样填：展示文字与 QVariant 业务值。
  • 作用与返回结果：追加选项，返回 void。
  • 调用时机与易错点：名称可翻译；稳定业务编号放 data，不依赖展示文本。

currentText() / currentData()

  • 参数怎样填：无参数，currentData 可指定 role。
  • 作用与返回结果：分别返回展示 QString 与业务 QVariant。
  • 调用时机与易错点：没有合法当前项时要处理空值；编号不是当前索引的必然同义词。

setCurrentIndex(index)

  • 参数怎样填：int，下标从 0 开始。
  • 作用与返回结果：切换选项，可触发 currentIndexChanged。
  • 调用时机与易错点：程序修改也会触发；用户意图可根据需求选择 activated。

QLabel::setText(text)

  • 参数怎样填：新的显示文字。
  • 作用与返回结果：更新标签内容并请求重绘。
  • 调用时机与易错点：只改标签不等于改了业务计数。先更新唯一状态再刷新显示。

setWordWrap(enabled)

  • 参数怎样填：bool。
  • 作用与返回结果：使标签按可用宽度换行。
  • 调用时机与易错点：不解决所有布局约束；仍要检查长路径与缩放。

setEnabled(enabled)

  • 参数怎样填：bool。
  • 作用与返回结果：启用或禁用交互。
  • 调用时机与易错点：禁用按钮不能替代业务函数内部的“任务已运行”检查。

QSignalBlocker(object)

  • 参数怎样填：暂时阻止发信号的 QObject 指针。
  • 作用与返回结果：RAII 对象恢复进入作用域前的阻塞状态。
  • 调用时机与易错点：阻止过的信号不会离开作用域后补发；批量改完需明确刷新派生界面。

对话框与主窗口：参数、结果与时机

QDialog::open()

  • 参数怎样填：无参数。
  • 作用与返回结果：异步打开模态对话框，返回 void，调用者继续执行。
  • 调用时机与易错点：对话框不能是马上离开作用域的局部对象；通过 accepted/rejected 接结果。

QDialog::accept() / reject()

  • 参数怎样填：无参数。
  • 作用与返回结果：设置对话框结果并结束交互。
  • 调用时机与易错点：accept 前应完成验证；Cancel 不应已写入真实业务数据。

setAttribute(Qt::WA_DeleteOnClose)

  • 参数怎样填：属性枚举以及可选 bool。
  • 作用与返回结果：关闭后安排删除窗口。
  • 调用时机与易错点：成员观察指针可能失效；使用 QPointer 或明确复用策略。

QMainWindow::setCentralWidget(widget)

  • 参数怎样填：中央控件指针。
  • 作用与返回结果：将控件放进主窗口中心并由主窗口拥有。
  • 调用时机与易错点：不要直接对 QMainWindow setLayout，它已有自己的结构。

menuBar()->addMenu(title)

  • 参数怎样填：菜单标题。
  • 作用与返回结果：返回新建 QMenu 指针。
  • 调用时机与易错点：菜单属于界面结构，不把 SQL 或文件业务写进菜单数据中。

QMenu::addAction(text)

  • 参数怎样填：动作标题。
  • 作用与返回结果：返回 QAction 指针，常连接 triggered。
  • 调用时机与易错点：QAction 是命令模型，可由菜单和工具栏共同使用，不是 QPushButton。

QAction::setShortcut(sequence)

  • 参数怎样填：如 QKeySequence::Save。
  • 作用与返回结果：设置命令快捷键。
  • 调用时机与易错点：优先使用平台标准键序列；不要和输入控件必要编辑快捷键冲突。

QFileDialog::getOpenFileName(...) / getSaveFileName(...)

  • 参数怎样填：父窗口、标题、初始目录和过滤器等。
  • 作用与返回结果：返回选中路径 QString，取消通常返回空字符串。
  • 调用时机与易错点：选中路径不代表已经读取或保存成功；空路径不覆盖当前文档状态。

QMessageBox::question(...)

  • 参数怎样填：父窗口、标题、内容、候选按钮和默认按钮。
  • 作用与返回结果：返回用户选择的 StandardButton。
  • 调用时机与易错点：要分别处理 Save、Discard、Cancel；Save 之后还要检查真正的保存结果。

QCloseEvent::accept() / ignore()

  • 参数怎样填：无参数。
  • 作用与返回结果：允许本次关闭或保持窗口打开。
  • 调用时机与易错点：文件对话框取消或写入失败应 ignore，不能仅看用户曾按过 Save。

Ui::Form::setupUi(widget)

  • 参数怎样填：uic 生成的函数，传要安装界面的控件。
  • 作用与返回结果：创建 ui 中定义的控件、布局和属性。
  • 调用时机与易错点：不是 Qt 通用类的任意成员；不要手工编辑生成的 ui_*.h。

字符串、配置与文件：参数、结果与时机

QString::trimmed() / isEmpty()

  • 参数怎样填：无参数。
  • 作用与返回结果：前者返回去首尾空白的新字符串；后者返回长度是否为 0。
  • 调用时机与易错点：trimmed 不原地修改；必须接收结果或继续链式调用。

QString::arg(value)

  • 参数怎样填：占位符替换值，可链式调用。
  • 作用与返回结果：返回替换后的新 QString。
  • 调用时机与易错点：不是 SQL 参数绑定；需要控制小数格式时选择对应重载。

QString::toInt(ok, base)

  • 参数怎样填：可传 bool 指针与进制，默认十进制。
  • 作用与返回结果：返回 int；通过 ok 区分真实 0 与解析失败。
  • 调用时机与易错点：不要直接相信失败时的默认数字，也要额外检查业务范围。

QString::toUtf8() / fromUtf8(bytes)

  • 参数怎样填：前者无参数，后者接字节。
  • 作用与返回结果：在 Unicode 文本与 UTF-8 QByteArray 之间转换。
  • 调用时机与易错点：不要将半个多字节字符单独解码后拼接；协议先拆完整帧。

QString::size() / QByteArray::size()

  • 参数怎样填：无参数。
  • 作用与返回结果：分别表示 UTF-16 代码单元数和字节数。
  • 调用时机与易错点：都不自动等于用户看到的字符数；接口限制必须写清单位。

QSettings::value(key, defaultValue)

  • 参数怎样填：键名和键缺失时的默认 QVariant。
  • 作用与返回结果：返回 QVariant，可进一步检查转换结果。
  • 调用时机与易错点：默认值只处理缺失，不自动修复存在但内容损坏的值。

QSettings::setValue(key, value)

  • 参数怎样填：键名与新值。
  • 作用与返回结果：记录配置更新，返回 void。
  • 调用时机与易错点：不是数据库事务或密码加密；多个字段的更新语义需自行设计。

QSettings::sync() / status()

  • 参数怎样填：无参数。
  • 作用与返回结果：sync 同步存储；status 返回错误状态。
  • 调用时机与易错点：应在 sync 后检查状态并反馈保存失败，不能无条件显示成功。

QSettings::fileName()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回实际配置位置。
  • 调用时机与易错点：原生格式可能是注册表相关位置；本例选择显式 INI 便于观察。

QStandardPaths::writableLocation(type)

  • 参数怎样填：如 AppConfigLocation 或 AppDataLocation。
  • 作用与返回结果：返回当前应用对应的可写位置 QString。
  • 调用时机与易错点：查询前设置应用标识，可能为空；返回目录不表示文件已创建。

QDir::mkpath(path)

  • 参数怎样填：路径。
  • 作用与返回结果：返回 bool，递归创建目录或确认已存在。
  • 调用时机与易错点：失败需反馈，不能继续把写入错误解释成空数据。

QFile::open(mode)

  • 参数怎样填：ReadOnly、WriteOnly 等打开模式。
  • 作用与返回结果：返回 bool，成功后才能 read/write。
  • 调用时机与易错点：文件不存在、权限、目录等都会导致失败，读取前检查。

QFile::readAll()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回剩余可读 QByteArray。
  • 调用时机与易错点：空内容与读取失败不同，还需 error()；大文件不要不设上限地一次全读。

QIODevice::write(bytes)

  • 参数怎样填：要写入的 QByteArray。
  • 作用与返回结果：返回实际接受的字节数 qint64，-1 表示失败。
  • 调用时机与易错点：检查数值与目标长度；socket 接受不等于远端业务处理成功。

QSaveFile::commit()

  • 参数怎样填：无参数。
  • 作用与返回结果：完成临时写入并替换目标，返回 bool。
  • 调用时机与易错点：只在写入完全成功后调用；失败不能更新文档路径或清除修改标记。

errorString()

  • 参数怎样填：无参数；具体类如 QFile 或 socket。
  • 作用与返回结果：返回可读错误说明。
  • 调用时机与易错点：要先确认哪个对象和操作失败；旧错误文本不一定代表本次操作状态。

QTemporaryDir::isValid() / filePath(name)

  • 参数怎样填：检查目录或生成其内部文件路径。
  • 作用与返回结果：返回 bool / QString。
  • 调用时机与易错点：临时目录必须活过所有文件操作，离开作用域会自动清理。

QJsonDocument::fromJson(bytes, error)

  • 参数怎样填：UTF-8 JSON 字节与错误输出指针。
  • 作用与返回结果：返回文档对象；error 提供语法错误。
  • 调用时机与易错点：语法合法后仍需 isObject/isArray 和逐字段类型校验。

QJsonDocument::toJson(format)

  • 参数怎样填：默认缩进或 Compact。
  • 作用与返回结果：返回序列化 QByteArray。
  • 调用时机与易错点：不自动验证你的业务规则或承诺旧版本兼容。

QJsonObject::value(key)

  • 参数怎样填：字符串键。
  • 作用与返回结果：返回 QJsonValue，之后检查类型再读取。
  • 调用时机与易错点：缺失、null、空文本含义不同，不能全部默认成合法数据。

QWidget::setStyleSheet(qss)

  • 参数怎样填：样式字符串。
  • 作用与返回结果：更新控件样式。
  • 调用时机与易错点：不是 HTML/CSS 浏览器；样式只能改变展示，不能完成业务状态迁移。

QTextDocument::setModified(false)

  • 参数怎样填：bool 修改标记。
  • 作用与返回结果：标记文档与保存状态一致。
  • 调用时机与易错点：仅在真正读取或保存成功后清除；失败时保留原状态。

模型、代理与索引：参数、结果与时机

rowCount(parent) / columnCount(parent)

  • 参数怎样填：父索引，平面表格通常只接受无效父索引。
  • 作用与返回结果：返回该父节点下的行列数 int。
  • 调用时机与易错点：对于有效父索引，简单平面模型通常返回 0，避免被误判为树。

data(index, role)

  • 参数怎样填：索引与所需角色，如 DisplayRole。
  • 作用与返回结果：返回 QVariant；不支持角色或非法位置返回空值。
  • 调用时机与易错点：显示、编辑、排序可读取不同角色，不能把所有角色都当字符串。

headerData(section, orientation, role)

  • 参数怎样填：表头位置、方向和角色。
  • 作用与返回结果：返回对应表头 QVariant。
  • 调用时机与易错点：只处理自定义情形，其他请求交回基类，避免破坏默认行号。

flags(index)

  • 参数怎样填：索引。
  • 作用与返回结果：返回可选、启用、可编辑等标志位。
  • 调用时机与易错点：单独增加 ItemIsEditable 不会自动实现保存，还需 setData。

setData(index, value, role)

  • 参数怎样填：目标、候选数据和编辑角色。
  • 作用与返回结果：返回 bool；成功更新数据后发 dataChanged。
  • 调用时机与易错点：先校验范围与类型，失败不改原数据；不要仅刷新文字而不更新模型。

dataChanged(topLeft, bottomRight, roles)

  • 参数怎样填：受影响的矩形范围和角色列表。
  • 作用与返回结果：信号通知视图重新读取对应数据。
  • 调用时机与易错点：不是让数据自动改变；需先更新内部状态，再发通知。

beginInsertRows(parent, first, last) / endInsertRows()

  • 参数怎样填：插入范围，first/last 包括两端。
  • 作用与返回结果：在修改容器前后成对通知视图。
  • 调用时机与易错点：begin 在旧结构仍有效时调用；不能修改完才通知开始。

setSourceModel(model) / setModel(model)

  • 参数怎样填：分别属于代理模型和视图。
  • 作用与返回结果：连接源数据到代理、代理到视图。
  • 调用时机与易错点：视图不因此任意接管模型所有权，应明确 parent 或普通对象寿命。

setFilterKeyColumn(column)

  • 参数怎样填：待筛选的列号；-1 有其多列语义。
  • 作用与返回结果：设置筛选列。
  • 调用时机与易错点：本例任务标题在第 0 列，选错列会让查询结果看似丢失。

setFilterFixedString(text)

  • 参数怎样填：用户筛选文字。
  • 作用与返回结果：按固定字符串规则过滤。
  • 调用时机与易错点：与正则表达式筛选不同，用户输入正则符号不会自动成为模式。

mapToSource(proxyIndex)

  • 参数怎样填：当前代理索引。
  • 作用与返回结果：返回源模型索引。
  • 调用时机与易错点：删除和更新先检查有效性，再读稳定主键；代理行号不是数据库 id。

currentIndex() / isValid()

  • 参数怎样填：视图取当前项，索引检查有效性。
  • 作用与返回结果：返回 QModelIndex / bool。
  • 调用时机与易错点：没有选中或模型已 reset 时旧索引可能无效，不能继续读取旧行。

setSortingEnabled(true)

  • 参数怎样填：视图 bool。
  • 作用与返回结果：允许表头触发排序。
  • 调用时机与易错点：字典序的字符串“10”可能先于“2”，数值排序要提供合适类型或角色。

绘图、事件与计时：参数、结果与时机

QTimer::start(interval) / stop()

  • 参数怎样填：间隔毫秒或停止无参数。
  • 作用与返回结果：开始或停止 timeout 通知。
  • 调用时机与易错点：定时器必须在所属线程正确使用；不保证实时频率，GUI 忙时会延迟。

QWidget::update()

  • 参数怎样填：无参数或更新区域。
  • 作用与返回结果：安排稍后的重绘请求，返回 void。
  • 调用时机与易错点：不是立即递归调用 paintEvent；多个请求可能合并，适合状态变化后使用。

paintEvent(event)

  • 参数怎样填：Qt 传入 QPaintEvent 指针。
  • 作用与返回结果：由 QWidget 绘制调度调用，返回 void。
  • 调用时机与易错点：不要在构造函数里直接调用来替代事件系统；普通控件 QPainter 在此创建。

QPainter(this)

  • 参数怎样填：绘制设备，这里是当前 QWidget。
  • 作用与返回结果：开始当前绘制过程，局部对象析构后结束。
  • 调用时机与易错点：只能在允许绘制的时机操作该设备，不保留跨事件的活动 painter。

setRenderHint(QPainter::Antialiasing)

  • 参数怎样填：渲染提示与可选 bool。
  • 作用与返回结果：开启边缘抗锯齿。
  • 调用时机与易错点：改善边缘，不改变几何计算或解决低分辨率图片问题。

translate(x,y) / scale(sx,sy)

  • 参数怎样填：平移距离或缩放比例。
  • 作用与返回结果：改变后续绘图的坐标变换。
  • 调用时机与易错点：顺序会改变结果；常先移到窗口中心，再缩放逻辑画布。

setPen(pen) / setFont(font)

  • 参数怎样填：画笔与字体对象。
  • 作用与返回结果：设置后续绘图状态。
  • 调用时机与易错点：状态会继续影响后面的命令，局部修改可配 save/restore。

drawArc(rect, start, span)

  • 参数怎样填：外接矩形、起角和跨度。
  • 作用与返回结果：绘制圆弧；Qt 角度单位为 1/16 度。
  • 调用时机与易错点：不是弧度；正负跨度影响方向，示例乘 16 是有意转换。

drawText(rect, flags, text)

  • 参数怎样填：区域、对齐/布局标志和文字。
  • 作用与返回结果：在区域内绘制文本。
  • 调用时机与易错点：区域过小会裁切；设置字体后重新检查布局和缩放。

eventFilter(watched, event)

  • 参数怎样填：被观察对象与事件指针。
  • 作用与返回结果：返回 true 表示过滤掉本次事件。
  • 调用时机与易错点：只处理明确条件，其他交给基类；检查 type 后才能安全转换具体事件类型。

QElapsedTimer::start() / elapsed()

  • 参数怎样填：开始无参数，读取无参数。
  • 作用与返回结果：记录起点与经过的毫秒数。
  • 调用时机与易错点：用于测持续时间；日历时间与时区使用 QDateTime，不能混用。

线程、HTTP 与 TCP：参数、结果与时机

QThread::start() / isRunning()

  • 参数怎样填：启动可指定优先级；查询无参数。
  • 作用与返回结果：启动线程 / 返回 bool。
  • 调用时机与易错点：线程开始不等于业务已经完成；重复点击前检查实际状态。

requestInterruption() / isInterruptionRequested()

  • 参数怎样填：无参数。
  • 作用与返回结果：发协作取消请求 / 查询 bool。
  • 调用时机与易错点：请求不会强杀线程，工作代码需周期检查，阻塞操作还需有界超时。

QThread::quit() / wait()

  • 参数怎样填：请求事件循环结束 / 可指定等待上限。
  • 作用与返回结果：quit 返回 void，wait 返回 bool。
  • 调用时机与易错点：quit 不会中断正在执行的长循环；GUI 上长时间 wait 会冻结界面。

QNetworkAccessManager::get(request)

  • 参数怎样填：QNetworkRequest。
  • 作用与返回结果：返回 QNetworkReply 指针，网络异步继续。
  • 调用时机与易错点：调用返回不是请求完成；reply 生命周期与 finished/error 处理必须清楚。

QNetworkRequest::setTransferTimeout(ms)

  • 参数怎样填：无数据传输超时毫秒数。
  • 作用与返回结果：设置传输超时策略。
  • 调用时机与易错点：不等同于所有情况下的总时限；课程另外设 singleShot 总时限。

QNetworkReply::attribute(code)

  • 参数怎样填：如 HttpStatusCodeAttribute。
  • 作用与返回结果：返回 QVariant 状态信息。
  • 调用时机与易错点：无 HTTP 响应时可能没有状态码，不能把 0 当作正常 HTTP 状态。

QNetworkReply::error() / abort()

  • 参数怎样填：查询或主动终止。
  • 作用与返回结果：返回错误枚举 / void。
  • 调用时机与易错点：abort 也会进入结束路径；恢复按钮和释放 reply 不应只写在成功分支。

QTcpServer::listen(address, port)

  • 参数怎样填：监听地址和端口；0 请求系统分配。
  • 作用与返回结果：返回 bool；成功后用 serverPort 取实际端口。
  • 调用时机与易错点：本例只用 LocalHost；不要无意改为 Any 后把教学服务开放给局域网。

nextPendingConnection()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回待处理服务端 socket 指针。
  • 调用时机与易错点：在 newConnection 后处理；为每条连接保留独立解析器，并在断开后销毁。

QTcpSocket::connectToHost(address, port)

  • 参数怎样填：地址与端口。
  • 作用与返回结果：启动异步连接，返回 void。
  • 调用时机与易错点：等待 connected 或 errorOccurred；不要在 GUI 中 waitForConnected 阻塞。

bytesAvailable() / read(maxSize)

  • 参数怎样填：可读字节数查询或最大读取量。
  • 作用与返回结果：返回 qint64 / QByteArray。
  • 调用时机与易错点：一次读取不保证整帧，解析器必须保存尾部残留数据。

setReadBufferSize(bytes)

  • 参数怎样填：最大接收缓冲字节数，0 有无限制语义。
  • 作用与返回结果：限制 socket 接收缓冲。
  • 调用时机与易错点：业务拆帧缓存、发送队列和日志也需分别设上限。

LineProtocol::feed(bytes, lines)

  • 参数怎样填：自定义解析器；输入字节和输出完整行列表。
  • 作用与返回结果：返回 bool，false 表示超过帧上限。
  • 调用时机与易错点：按 LF 取帧，残留半帧保存在内部；false 时调用方终止连接，不把损坏数据当正常消息。

数据库与 TaskDesk：参数、结果与时机

QSqlDatabase::addDatabase(driver, name)

  • 参数怎样填：如 QSQLITE 和唯一连接名。
  • 作用与返回结果：返回连接句柄。
  • 调用时机与易错点：同名会影响旧连接；一个句柄拷贝不是新建独立连接。

setDatabaseName(path) / open()

  • 参数怎样填：路径或 :memory:；打开无参数。
  • 作用与返回结果：设置目标 / open 返回 bool。
  • 调用时机与易错点：失败检查 lastError；SQLite 内存库退出即丢，不能当持久化。

QSqlQuery::prepare(sql)

  • 参数怎样填：含 ? 或命名占位符的 SQL。
  • 作用与返回结果：返回 bool。
  • 调用时机与易错点：准备也会失败；表名和排序字段不能作为普通值占位符绑定。

addBindValue(value) / bindValue(index, value)

  • 参数怎样填：顺序追加值或按位置更新值。
  • 作用与返回结果：把值交给驱动，返回 void。
  • 调用时机与易错点：与 SQL 中占位符顺序对应，不通过 arg 拼接用户标题。

QSqlQuery::exec()

  • 参数怎样填：执行已准备语句，或传 SQL 的重载。
  • 作用与返回结果：返回 bool。
  • 调用时机与易错点：成功不代表一定匹配到某一行；更新/删除还检查受影响行数。

QSqlQuery::next() / value(column)

  • 参数怎样填：推进到下一条结果 / 当前行列号。
  • 作用与返回结果：返回 bool / QVariant。
  • 调用时机与易错点：必须先 next 成功再读 value；不要把查询失败当作合法空结果。

numRowsAffected()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回写操作影响行数，驱动无法提供时可有特殊值。
  • 调用时机与易错点：课程的单主键更新要求 1 行，0 行表示目标可能已经不存在。

transaction() / commit() / rollback()

  • 参数怎样填：数据库连接成员，无参数。
  • 作用与返回结果：均返回 bool。
  • 调用时机与易错点：每个结果都检查；业务整批成功才提交，失败回滚，不弹成功提示。

QSqlQuery::finish()

  • 参数怎样填：无参数。
  • 作用与返回结果：结束活动结果集，保留查询对象。
  • 调用时机与易错点：有些数据库提交前需结束查询；销毁连接前还需让模型和查询退出作用域。

QSqlDatabase::removeDatabase(name)

  • 参数怎样填：连接名。
  • 作用与返回结果：移除命名连接。
  • 调用时机与易错点：不能仍有活动 query/model/外部句柄引用该连接；先销毁使用者。

TaskStore::open(path)

  • 参数怎样填：课程仓储自定义接口。
  • 作用与返回结果：返回 bool；打开并建表。
  • 调用时机与易错点：不是 Qt 自带函数；失败用 store.error 读课程保存的错误。

TaskStore::add(title)

  • 参数怎样填：候选标题。
  • 作用与返回结果：trim 后校验 1~200 UTF-16 单元，成功写入返回 true。
  • 调用时机与易错点：UI 通过验证不代表其他调用者不会绕过，仓储仍要保护规则。

TaskStore::complete(id, done) / remove(id)

  • 参数怎样填：稳定主键与目标完成状态，或删除主键。
  • 作用与返回结果：返回 bool，要求真正影响一行。
  • 调用时机与易错点：id 不是排序后的可见行号；操作后刷新展示并处理失败。

QML、测试与工程诊断：参数、结果与时机

QQmlApplicationEngine::loadFromModule(uri, typeName)

  • 参数怎样填：课程使用 Course 与 Main。
  • 作用与返回结果：加载模块中的根类型，返回 void。
  • 调用时机与易错点：配置 URI、资源名或 required 属性错误会使创建失败，连接 objectCreationFailed 处理退出。

Q_PROPERTY(... READ ... NOTIFY ...)

  • 参数怎样填：这是元对象声明宏，不是运行时函数。
  • 作用与返回结果：使属性可被读取并通知变化。
  • 调用时机与易错点：NOTIFY 的发送必须由你的代码保证；getter 不应执行长时间磁盘或网络工作。

Counter::increment()

  • 参数怎样填：课程自定义 Q_INVOKABLE，无参数。
  • 作用与返回结果：改变 count 并发 countChanged。
  • 调用时机与易错点：Q_INVOKABLE 只暴露调用能力，不自动启动线程。

QSignalSpy(sender, signal)

  • 参数怎样填：被观察对象和信号指针。
  • 作用与返回结果：创建信号记录器，用 isValid 检查。
  • 调用时机与易错点：尽量在动作前创建，以免错过已经同步发出的信号。

QSignalSpy::wait(timeout)

  • 参数怎样填：最长等待毫秒数。
  • 作用与返回结果：在超时内收到新信号返回 true。
  • 调用时机与易错点：先检查已有数量再 wait，避免信号已发生却继续等待下一次。

QVERIFY(expr) / QCOMPARE(actual, expected)

  • 参数怎样填：测试条件或实际值与期望值。
  • 作用与返回结果：失败记录上下文并结束当前测试函数。
  • 调用时机与易错点：它们是测试宏，不是给真实用户处理错误的界面。

QTRY_VERIFY(expr) / QTRY_COMPARE(actual, expected)

  • 参数怎样填：可在事件循环中逐步成立的条件。
  • 作用与返回结果：重试直到成立或超时。
  • 调用时机与易错点：不是无限等待；比固定 sleep 更能适应不同机器速度。

QTest::mouseClick(widget, button)

  • 参数怎样填：控件与鼠标按钮等参数。
  • 作用与返回结果：模拟交互。
  • 调用时机与易错点：应测真实窗口的用户结果，而不是仅证明 Qt 自带按钮能发信号。

QLoggingCategory(...) / qCWarning(category)

  • 参数怎样填：日志分类和输出表达式。
  • 作用与返回结果：按类别组织诊断。
  • 调用时机与易错点：不会自动写日志文件、轮转或删除敏感信息，仍需明确日志策略。

QProcess 等外部工具

  • 参数怎样填：本课程部署脚本实际调用 windeployqt，而非此处启动 Qt 类。
  • 作用与返回结果：部署命令收集 DLL、插件和 QML。
  • 调用时机与易错点：工具返回成功不证明所有 GPU、驱动、用户输入路径和第三方许可均已验收。

如何从手册回到源码

阅读完一组后运行对应示例，先预测再观察。对 bool 返回值故意制造一次失败，对异步调用记录开始和完成日志，对 QObject 画所有权树。自定义 TaskStore、LineProtocol、Counter 的语义由本仓库源码定义；它们不是可以在任意 Qt 程序中直接使用的系统 API。

构造函数与其余辅助接口逐项补充

构造函数创建对象，成员函数才操作已有对象。以下补齐示例中容易被一笔带过的调用；同名方法要看接收对象。

QPushButton(text, parent)

  • 参数：按钮标题和父控件。
  • 作用与返回：构造按钮对象，不执行点击。
  • 为什么要这样调用：连接 clicked 响应操作；parent 决定销毁责任。

QLineEdit(parent) / QLineEdit(text,parent)

  • 参数：父控件或初始文字加父控件。
  • 作用与返回：创建单行编辑器。
  • 为什么要这样调用：提示文字用 placeholder，不把提示当实际业务输入。

QSpinBox(parent) / QSlider(orientation,parent)

  • 参数：父控件，滑块还指定方向。
  • 作用与返回：创建数值输入与连续调节界面。
  • 为什么要这样调用：构造后先设范围和默认值，再建立需要的同步连接。

QCheckBox(text,parent)

  • 参数：标题与父控件。
  • 作用与返回：创建独立开关。
  • 为什么要这样调用：构造不会替用户确认，提交仍要读取状态。

QTableView(parent) / QPlainTextEdit(parent)

  • 参数：父控件。
  • 作用与返回：创建表格视图或纯文本编辑器。
  • 为什么要这样调用：视图需要模型；日志编辑器通常设只读并限制最大行数。

QUrl::scheme() / host() / isValid()

  • 参数：无参数。
  • 作用与返回：返回协议、主机名或语法有效性。
  • 为什么要这样调用：合法 URL 还应检查应用允许的协议；本例仅允许 HTTP/HTTPS 且主机非空。

QString::number(value)

  • 参数：数值及可选进制/格式参数。
  • 作用与返回：返回数值的字符串表示。
  • 为什么要这样调用：不是输入验证；地区化展示应根据需求使用 QLocale。

QVariant::toString() / toByteArray()

  • 参数：无参数。
  • 作用与返回：提取转换后的文本或字节数组。
  • 为什么要这样调用：转换结果不等于业务合法，几何状态字节也不是可读标题。

QString::clear() / QLineEdit::clear()

  • 参数：无参数。
  • 作用与返回：清空字符串值或控件文本。
  • 为什么要这样调用：注意接收者类型，控件清空可能触发信号，普通字符串清空不会更新其他控件。

QPlainTextEdit::appendPlainText(text)

  • 参数：追加的普通文本。
  • 作用与返回：追加日志段落。
  • 为什么要这样调用：不是富文本 HTML；长期日志需限制容量。

QTextEdit::toPlainText() / setPlainText(text)

  • 参数：无参数读取，QString 写入。
  • 作用与返回：读取或替换纯文本内容。
  • 为什么要这样调用：替换可能改变文档修改状态；成功读文件后才明确清除修改标记。

QTextEdit::document()

  • 参数：无参数。
  • 作用与返回：返回关联 QTextDocument 指针。
  • 为什么要这样调用：文档拥有内容和修改标记，不是文件句柄。

QTextDocument::isModified()

  • 参数：无参数。
  • 作用与返回：返回内容是否被标记为修改。
  • 为什么要这样调用：它不替你判断磁盘上的外部修改，需要另外设计文件变化检测。

QTextDocument::setMaximumBlockCount(count)

  • 参数：最大段落块数量。
  • 作用与返回：限制日志保留规模，超过时移除旧块。
  • 为什么要这样调用：限制块数不等于限制总字节数，单条日志也要合理有界。

setReadOnly(true)

  • 参数：用于文本输入控件的 bool。
  • 作用与返回：禁止用户修改但仍可展示内容。
  • 为什么要这样调用：不等于禁用所有选择和复制，日志可按需继续允许复制。

setTextInteractionFlags(flags)

  • 参数：如 TextSelectableByMouse。
  • 作用与返回：配置 QLabel 文本交互。
  • 为什么要这样调用：它不是 QLineEdit 的编辑模式，也不提供保存文件功能。

QWidget::saveGeometry() / restoreGeometry(bytes)

  • 参数：读取无参数，恢复接 QByteArray。
  • 作用与返回：返回几何状态字节 / 恢复成功 bool。
  • 为什么要这样调用：读自配置后尝试恢复，屏幕布局改变仍要检查窗口可见性。

QCoreApplication::setOrganizationName(name) / setApplicationName(name)

  • 参数：应用标识字符串。
  • 作用与返回：设定默认配置与用户路径的应用身份。
  • 为什么要这样调用：在创建默认 QSettings 和查询应用路径前设置，避免写入不同目录。

QStandardPaths::setTestModeEnabled(true)

  • 参数：bool。
  • 作用与返回：使部分用户位置采用测试位置。
  • 为什么要这样调用：不是无限制的全局文件安全隔离；本例仍用 QTemporaryDir 放自检配置。

QTimer::setInterval(ms) / setSingleShot(true)

  • 参数：毫秒间隔或单次模式。
  • 作用与返回：改变定时器运行策略。
  • 为什么要这样调用：setInterval 本身不等于对未运行定时器 start；防抖需每次输入重新启动。

QThread::currentThread() / msleep(ms)

  • 参数：当前线程查询或毫秒数。
  • 作用与返回：返回当前执行线程对象 / 让调用线程睡眠。
  • 为什么要这样调用：不要在 GUI 线程睡眠；本例只在 worker 内模拟耗时。

QFont::setPixelSize(size)

  • 参数：像素字号 int。
  • 作用与返回：设置绘图文字字号。
  • 为什么要这样调用：与 setPointSize 的单位不同，改变字号后重新检查绘制区域。

QPalette::text().color()

  • 参数：获取文本颜色角色的画刷再取颜色。
  • 作用与返回：返回颜色值。
  • 为什么要这样调用：使用系统主题颜色能改善可读性，但自绘背景也需考虑对比。

setFilterCaseSensitivity(mode)

  • 参数：Qt::CaseInsensitive 等枚举。
  • 作用与返回：设置代理筛选大小写策略。
  • 为什么要这样调用：与排序大小写策略不是必然同一开关。

QTcpServer::hasPendingConnections()

  • 参数：无参数。
  • 作用与返回：返回是否有待取连接。
  • 为什么要这样调用：配合 while 与 nextPendingConnection 处理积压连接，不等同于某个客户端仍在线。

QTcpSocket::bytesToWrite()

  • 参数：无参数。
  • 作用与返回：返回待写出的缓冲字节数。
  • 为什么要这样调用：用于发送背压；0 不证明远端已处理，仍需应用协议响应。

QTcpSocket::close() / abort()

  • 参数：无参数。
  • 作用与返回：关闭或立即终止 socket；abort 丢弃待写数据。
  • 为什么要这样调用：优雅断开与立即中止语义不同；对错误帧本例选择 abort。

QFile::close()

  • 参数：无参数。
  • 作用与返回：关闭本文件设备。

QImage::isNull() / pixelColor(x,y)

  • 参数：无参数或图像像素坐标。
  • 作用与返回：返回是否无图像 / QColor。
  • 为什么要这样调用：读回图像前先检查有效性，坐标使用图像实际尺寸，防止越界。

qInfo().noquote()

  • 参数：日志输出流操纵器。
  • 作用与返回：取消输出 QString 时默认引号。
  • 为什么要这样调用：不会取消隐私过滤责任，也不会自动保存日志文件。

QMessageBox::warning(parent,title,text)

  • 参数：父窗口、标题、错误文字。
  • 作用与返回：展示警告并返回选择结果。
  • 为什么要这样调用：仅业务界面层弹窗，仓储和后台线程不要直接弹 GUI。

Triangle::ready() / error()

  • 参数：示例 17 的自定义只读方法。
  • 作用与返回：返回 GPU 初始化成功标志 / 保存的初始化日志。
  • 为什么要这样调用：不是 Qt 通用接口；ready 不等同于已经证明所有像素都正确。
