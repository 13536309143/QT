01 · 零基础预备课：读懂一小段 C++

建议位置：在第 04 章之前。目标：能逐行解释变量、判断、循环和函数；不要求先掌握全部 C++。

先区分四种东西

写法 含义 Qt 中的例子
int minutes = 30; 声明一个整数并初始化 每天学习分钟数
minutes = 45; 给已有变量赋新值 修改学习计划
minutes == 45 比较，结果为 bool 判断是否达到目标
QString name Qt 的文本类型 姓名或按钮文字

变量名区分大小写；语句通常以分号结尾。= 和 == 含义不同，条件里误写赋值有时仍能编译，所以“编译成功”不等于“意思正确”。花括号构成作用域，块内声明的局部变量一般不能在块外访问。

判断、循环与提前返回

int totalMinutes(int days, int perDay) {
    if (days < 0 || perDay < 0) return 0;
    int total = 0;
    for (int day = 0; day < days; ++day) {
        total += perDay;
    }
    return total;
}

|| 表示“或”，&& 表示“并且”，! 表示“取反”。先在纸上计算 totalMinutes(3, 20)：day 依次为 0、1、2，函数返回 60。day < days 使循环执行三次，改成 <= 就多执行一次。这里用循环是为了练习，实际业务可在检查溢出的前提下直接乘法。

返回值帮助调用者决定下一步；void 表示没有返回值。参数是函数接收的数据，调用时传入的具体值是实参。变量作用域和对象存活时间有关，下一章会继续解释为什么异步回调不能引用已经消失的局部对象。

第一次读 Qt 表达式

QString name = QStringLiteral("小明");
name = name.trimmed();
bool missing = name.isEmpty();

点号表示访问对象成员。trimmed() 返回去掉首尾空白的新字符串，单独调用而不接收结果不会改掉原来的 name。button->setText(...) 中箭头用于指针；它与点号的区别来自变量类型，而不是控件是否“高级”。

#include 引入声明，// 开始行注释；QStringLiteral 用于构造字符串字面量。先认识这些写法，不要一开始就把所有宏展开背下来。

动手步骤与参考结果

  1. 在 01_hello 的 app.exec() 前打印 totalMinutes(3, 20)，把函数放在 main 前。
  2. 分别传入 0、1、3 和负数天数，写下预期再运行。
  3. 故意把 < 改成 <=，解释结果为什么多 20。
  4. 恢复代码，再增加“每天至少 5 分钟”的判断。

验收：能解释声明与赋值、参数与返回值、一次循环与事件循环的差别。遇到错误先看第一条诊断及所在行，不把整段代码全部改写。
