05 · 第一个窗口与事件循环

阅读 01_hello

首先包含 QApplication 和 QLabel。创建 QApplication 后再创建控件，因为 GUI 对象需要应用级初始化。QLabel 是显示文本的控件；不给 QWidget 父对象，它就可以成为顶层窗口。resize 设置初始尺寸；show 使窗口可见；app.exec() 开始分发操作系统事件。

这不是从上到下执行完就结束的脚本。事件循环不断等待鼠标、键盘、定时器和重绘请求，并分派给相关对象。窗口关闭后，在默认配置下最后一个顶层窗口关闭会让应用退出。show() 后还没有进入循环时，窗口可能尚未来得及真正绘制。

操作步骤

  1. 运行 scripts\run.cmd 01_hello，观察窗口标题、居中文字和默认尺寸。
  2. 把文本改为两行自我介绍，重新构建目标后运行。
  3. 去掉 setAlignment，观察默认对齐方式；恢复后将尺寸减小。
  4. 在 exec 前加入日志，关闭窗口后在 exec 返回处再打印日志，理解程序停留在哪里。

不要阻塞 GUI 线程

若在点击处理里运行十秒循环，鼠标响应、重绘和定时器都会被拖住。插入 processEvents() 可能引入嵌套调用和对象提前销毁，不应成为耗时任务的常规解决方案。短任务用定时器分批，长任务交给后台线程。

程序还支持 --smoke 参数，短暂进入事件循环后自动退出，供自动检查启动使用。这只能证明程序能初始化，不能替代实际点击、输入和缩放的交互验收。

练习：增加最小尺寸和窗口标题。验收：窗口能缩放，文本没有固定位置溢出；能说明 QApplication 与 QWidget 的析构顺序为何合理。

配套完整源码

在根工程构建本章目标：01_hello。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QApplication>
#include <QLabel>
#include <QTimer>
int main(int argc, char *argv[]) {
    QApplication app(argc, argv); // QApplication 必须先于任何 QWidget 创建
    QLabel label(QStringLiteral("你好，Qt！\n缩放窗口试试看。"));
    label.setAlignment(Qt::AlignCenter);
    label.resize(480, 260);
    label.setWindowTitle(QStringLiteral("01 · 第一个窗口"));
    label.show();
    if (app.arguments().contains("--smoke")) QTimer::singleShot(150, &app, &QCoreApplication::quit);
    return app.exec(); // 进入事件循环，关闭最后一个窗口后退出
}
