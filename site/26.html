26 · QPainter：坐标、抗锯齿和仪表盘

绘图放在哪里

QWidget 的绘图写在 paintEvent，用 QPainter 绑定当前控件。状态改变时调用 update 安排重绘，由 Qt 合并多次请求。不要保存 QPainter 作为长期成员，也不要在按钮处理里直接拿它画完就以为图像永久存在。

本例用 translate 将原点移到中心，再 scale 把逻辑坐标映射到当前窗口。这样无论窗口大小，圆弧仍按相同比例绘制。抗锯齿让曲线边缘平滑，但会增加开销；一般仪表盘可启用，大量实时点则应先测量。

QPainter 角度采用 1/16 度，drawArc 的起始角和跨度方向要独立理解。示例不是医疗或工业仪表，仅用于练习动画与缩放。定时器每次改变 value_ 后 update，paintEvent 只读取状态绘制，不再启动定时器或修改业务数据。

高 DPI 和交互

Qt 6 默认具备高 DPI 支持。逻辑坐标与设备像素不是一回事；使用 QPixmap 离屏缓存时要考虑 devicePixelRatio。先采用矢量绘图和合理字体尺寸，比手工把每个坐标乘系统缩放更可靠。

练习：添加刻度、最小最大值和单位，窗口保持圆形而非拉成椭圆。验收：最小窗口中文字不与圆弧重叠；反复最小化和恢复图像仍完整。进阶：实现 setValue，只在数值实际变化时 update，并对 0~100 做边界处理。 参考：绘图系统。

配套完整源码

在根工程构建本章目标：07_paint。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QtWidgets>
#include <QtMath>
class Gauge : public QWidget {
public:
    Gauge() {
        auto *timer=new QTimer(this);
        connect(timer,&QTimer::timeout,this,[this] { value_=(value_+1)%101; update(); });
        timer->start(50); resize(420,320);
    }
protected:
    void paintEvent(QPaintEvent *) override {
        QPainter p(this); p.setRenderHint(QPainter::Antialiasing);
        const int side=qMin(width(),height());
        p.translate(width()/2.0,height()/2.0); p.scale(side/240.0,side/240.0);
        p.setPen(QPen(QColor("#334155"),12)); p.drawArc(QRectF(-90,-90,180,180),30*16,300*16);
        p.setPen(QPen(QColor("#16a085"),12)); p.drawArc(QRectF(-90,-90,180,180),210*16,-value_*3*16);
        p.setPen(palette().text().color()); QFont font=p.font(); font.setPixelSize(32); p.setFont(font);
        p.drawText(QRectF(-70,-30,140,60),Qt::AlignCenter,QString::number(value_));
    }
private: int value_=0;
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); Gauge w; w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
