20 · 资源系统、QSS 与界面风格

资源打包

qrc 文件声明资源前缀和文件，rcc 将它们编进程序。示例使用 :/lesson/readme.txt 读取资源；Quick 里常见 qrc:/ URL。资源路径与磁盘绝对路径不同，也不随工作目录改变。资源是只读的，用户改过的配置应另存到可写目录。

QSS 能做什么

Qt Style Sheets 可以设置颜色、边框、间距和部分控件外观，语法与 CSS 相似但能力不同。浏览器 CSS 的所有布局、动画和选择器不能原样套用。优先让布局负责几何，QSS 负责外观。

QPushButton { padding: 8px 16px; border-radius: 6px; }
QPushButton:hover { background: #d9eee8; }
QLineEdit:focus { border: 1px solid #168477; }

示例把 theme.qss 也放进资源。修改后要重建才能看到变化。若运行时允许用户切换主题，可加载不同资源并设置 application 或窗口样式；注意局部样式的继承和覆盖关系。不要靠把所有字体都固定为很小像素来获得“精致”界面。

练习：给资源示例补充 hover、pressed、disabled 三种按钮状态；再新增一个带 objectName 的强调按钮，只对它应用样式。验收：禁用状态可辨认，键盘焦点仍可见，浅色背景上的文本有足够对比度。图标可使用自己制作或许可清楚的素材，并在仓库记录来源。

进阶：主题颜色抽成少量设计变量，通过生成 QSS 或统一调色板维护。QSS 复杂到难以预测时，先精简选择器并检查控件真实类名。

配套完整源码

在根工程构建本章目标：12_resources。以下是仓库内同一份文件，修改请到 examples 目录。

assets.qrc

<RCC><qresource prefix="/lesson"><file>readme.txt</file><file>theme.qss</file></qresource></RCC>

main.cpp

#include <QtWidgets>
int main(int argc,char **argv) {
    QApplication app(argc,argv); QWidget w; auto *layout=new QVBoxLayout(&w);
    QFile text(":/lesson/readme.txt");
    if(!text.open(QIODevice::ReadOnly)) return 1;
    auto *label=new QLabel(QString::fromUtf8(text.readAll()),&w); layout->addWidget(label);
    QFile style(":/lesson/theme.qss");
    if(style.open(QIODevice::ReadOnly)) w.setStyleSheet(QString::fromUtf8(style.readAll()));
    layout->addWidget(new QPushButton(QStringLiteral("资源加载成功"),&w));
    w.resize(420,200); w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}

theme.qss

QWidget { background: #eef5fa; color: #18354a; font-size: 16px; } QPushButton { padding: 12px; border: 1px solid #168477; border-radius: 6px; }
