23 · Qt Quick 与 QML：声明式界面

为什么还要一条界面路线

Widgets 更接近传统桌面控件；Qt Quick 使用 QML 描述界面层级、属性绑定和动画。本课程不是把 Widgets 翻译成 QML，而是学习“界面由状态推导”的方式。业务逻辑仍可放 C++，QML 负责展示和交互。

13_quick 的 ApplicationWindow 是根窗口，ColumnLayout 排列文字和按钮，Counter 是课程提供的 C++ 类型。Label 的 text 绑定 backend.count，当 NOTIFY 发出后自动重新计算。

Label { text: "次数：" + backend.count }
Button { text: "增加"; onClicked: backend.increment() }

不要在点击事件里给绑定过的 text 强行赋一个常量再期望原绑定继续工作。用统一状态来源，减少同一数据在 C++ 与 QML 两侧各存一份造成不同步。

布局规则

anchors 适合将对象锚定到父容器；RowLayout/ColumnLayout 适合按建议尺寸分配空间。在同一对象上同时用相互冲突的 anchors 和 Layout 几何规则会产生警告或不可预期结果。布局内部子项一般使用 Layout.preferredWidth 等提示，外层容器可以 anchors.centerIn。

构建使用 qt_add_qml_module 注册 Course 模块，URI 不是随意磁盘目录名。缺少 QtQuick.Controls 通常表示运行路径或 SDK 模块不完整，先核对 QML_IMPORT_PATH 和 Kit，不要从其他 Qt 版本复制目录。

练习：增加复位按钮和最大次数提示。验收：改动 count 后标签自动更新，终端无 binding loop 和 module not installed 警告。 参考：QML 构建。

配套完整源码

在根工程构建本章目标：13_quick。以下是仓库内同一份文件，修改请到 examples 目录。

CMakeLists.txt

find_package(Qt6 6.5 REQUIRED COMPONENTS Quick QuickControls2)
qt_standard_project_setup(REQUIRES 6.5)
qt_add_executable(13_quick main.cpp)
qt_add_qml_module(13_quick URI Course VERSION 1.0 QML_FILES Main.qml SOURCES counter.h)
target_link_libraries(13_quick PRIVATE Qt6::Quick Qt6::QuickControls2)

counter.h

#pragma once
#include <QObject>
#include <QtQml/qqmlregistration.h>
class Counter : public QObject {
    Q_OBJECT
    QML_ELEMENT
    Q_PROPERTY(int count READ count NOTIFY countChanged)
public:
    explicit Counter(QObject *parent=nullptr):QObject(parent) {}
    int count() const { return count_; }
    Q_INVOKABLE void increment() { ++count_; emit countChanged(); }
signals: void countChanged();
private: int count_=0;
};

main.cpp

#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include <QTimer>
int main(int argc,char **argv) {
    QGuiApplication app(argc,argv); QQmlApplicationEngine engine;
    QObject::connect(&engine,&QQmlApplicationEngine::objectCreationFailed,&app,[]{ QCoreApplication::exit(1); },Qt::QueuedConnection);
    engine.loadFromModule("Course","Main");
    if(app.arguments().contains("--smoke")) QTimer::singleShot(200,&app,&QCoreApplication::quit);
    return app.exec();
}

Main.qml

import QtQuick
import QtQuick.Controls
import QtQuick.Layouts
import Course
ApplicationWindow {
    width: 480; height: 320; visible: true; title: "Qt Quick + C++"
    Counter { id: backend }
    ColumnLayout {
        anchors.centerIn: parent; spacing: 20
        Label { text: "点击次数：" + backend.count; font.pixelSize: 28 }
        Button { text: "增加"; onClicked: backend.increment() }
    }
}
