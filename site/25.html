前置：第 24 章。目标：理解事件传播，给输入框增加行为且不吞掉正常操作。

四个观察层次

用户按键 → 焦点控件收到事件 → 控件处理 → 可能发出更高层信号。提交表单优先连接 returnPressed；菜单命令优先 QAction 的 shortcut；只有这些语义信号不够时才重写 keyPressEvent 或安装 eventFilter。

鼠标点击一个控件不代表任意自定义 QWidget 都能获得键盘焦点。自定义键盘控件需要合理的 focusPolicy；Tab 顺序需要按阅读顺序检查。禁用控件通常不能交互，隐藏控件也不应成为可见流程的必需步骤。

只拦截自己处理的事件

下面是 QWidget 子类中的成员函数片段，search_ 是成员 QLineEdit，构造时已调用 search_->installEventFilter(this)：

bool eventFilter(QObject *watched, QEvent *event) override {
    if (watched == search_ && event->type() == QEvent::KeyPress) {
        auto *key = static_cast<QKeyEvent *>(event);
        if (key->key() == Qt::Key_Escape) {
            search_->clear();
            return true;  // 本次 Esc 已经处理
        }
    }
    return QWidget::eventFilter(watched, event);
}

先检查事件类型，才把基类指针转换成 QKeyEvent。对所有事件返回 true，会使输入、绘图、焦点等功能失效。过滤器和目标对象需要合适的线程归属，不借过滤器跨线程操作界面。

高频输入不要直接触发昂贵工作

用户连续输入“Qt 教程”，不一定希望执行四次数据库搜索。创建 singleShot 的 250ms QTimer，每次 textChanged 重新 start；timeout 时读取当前文本发起查询。这叫防抖：连续输入暂不执行，停顿后执行一次。它与“每隔固定时间最多执行一次”的节流不同。

防抖只减少请求，不保证返回顺序正确。异步搜索还需要第 28 章的请求序号；用户清空输入时应立即恢复默认显示，或明确告知正在查询。

验收顺序

在 03_form 加搜索输入，依次验证普通输入、中文输入法、Backspace、方向键、Tab、Esc。Esc 只清空搜索框，其他按键行为保持正常。长按按键会有自动重复事件，若动作只允许执行一次需检查 isAutoRepeat。

练习答案要点：过滤范围限定到目标和特定事件；未处理情况交给基类；对于按钮命令先考虑 QAction 或快捷键。无法在当前环境测试输入法时记录限制，不据 ASCII 输入推断全部文字输入正确。

绘图、事件与计时：参数、结果与时机

QTimer::start(interval) / stop()

  • 参数怎样填：间隔毫秒或停止无参数。
  • 作用与返回结果：开始或停止 timeout 通知。
  • 调用时机与易错点：定时器必须在所属线程正确使用；不保证实时频率，GUI 忙时会延迟。

QWidget::update()

  • 参数怎样填：无参数或更新区域。
  • 作用与返回结果：安排稍后的重绘请求，返回 void。
  • 调用时机与易错点：不是立即递归调用 paintEvent；多个请求可能合并，适合状态变化后使用。

paintEvent(event)

  • 参数怎样填：Qt 传入 QPaintEvent 指针。
  • 作用与返回结果：由 QWidget 绘制调度调用，返回 void。
  • 调用时机与易错点：不要在构造函数里直接调用来替代事件系统；普通控件 QPainter 在此创建。

QPainter(this)

  • 参数怎样填：绘制设备，这里是当前 QWidget。
  • 作用与返回结果：开始当前绘制过程，局部对象析构后结束。
  • 调用时机与易错点：只能在允许绘制的时机操作该设备，不保留跨事件的活动 painter。

setRenderHint(QPainter::Antialiasing)

  • 参数怎样填：渲染提示与可选 bool。
  • 作用与返回结果：开启边缘抗锯齿。
  • 调用时机与易错点：改善边缘，不改变几何计算或解决低分辨率图片问题。

translate(x,y) / scale(sx,sy)

  • 参数怎样填：平移距离或缩放比例。
  • 作用与返回结果：改变后续绘图的坐标变换。
  • 调用时机与易错点：顺序会改变结果；常先移到窗口中心，再缩放逻辑画布。

setPen(pen) / setFont(font)

  • 参数怎样填：画笔与字体对象。
  • 作用与返回结果：设置后续绘图状态。
  • 调用时机与易错点：状态会继续影响后面的命令，局部修改可配 save/restore。

drawArc(rect, start, span)

  • 参数怎样填：外接矩形、起角和跨度。
  • 作用与返回结果：绘制圆弧；Qt 角度单位为 1/16 度。
  • 调用时机与易错点：不是弧度；正负跨度影响方向，示例乘 16 是有意转换。

drawText(rect, flags, text)

  • 参数怎样填：区域、对齐/布局标志和文字。
  • 作用与返回结果：在区域内绘制文本。
  • 调用时机与易错点：区域过小会裁切；设置字体后重新检查布局和缩放。

eventFilter(watched, event)

  • 参数怎样填：被观察对象与事件指针。
  • 作用与返回结果：返回 true 表示过滤掉本次事件。
  • 调用时机与易错点：只处理明确条件，其他交给基类；检查 type 后才能安全转换具体事件类型。

QElapsedTimer::start() / elapsed()

  • 参数怎样填：开始无参数，读取无参数。
  • 作用与返回结果：记录起点与经过的毫秒数。
  • 调用时机与易错点：用于测持续时间；日历时间与时区使用 QDateTime，不能混用。
