06 · QObject、元对象与父子所有权

对象树解决什么问题

QObject 提供父子关系、信号槽、属性和对象名称。父对象销毁时会销毁它拥有的子对象，子对象提前销毁时会从父对象列表移除。QWidget 的父对象还影响视觉层级，而普通 QObject 的父子关系主要表达所有权。

new QPushButton(this) 中 this 往往是窗口，它负责按钮的生命期。布局管理控件的几何位置，不能把布局的几何管理和 C++ 中所有权完全等同；把控件加入已经安装在窗口上的布局时，Qt 会把控件纳入合适的控件层级。

两个需要分清的名称

objectName 用来查找对象、应用样式或辅助测试；变量名只存在于 C++ 代码。修改变量名不会自动改变 Designer 中的 objectName。Q_OBJECT 启用派生类自己的信号、属性和元对象信息。只连接已有信号、不声明新信号的普通 QWidget 子类可以不写它。

deleteLater 和 QPointer

异步回调中正在处理事件的 QObject，常用 deleteLater() 安排在适当的事件循环时机删除。调用后不要继续把对象当作长久有效的对象。它依赖对应线程的事件分发/结束处理，不能把它理解为立即 delete。

QPointer<QWidget> tracked = window;
// 当 window 真正被 QObject 机制销毁后，tracked 变为空。
if (tracked) tracked->show();

QPointer 是观察指针，不延长对象生命期，也不是跨线程同步工具。不要把所有对象都改成 QPointer；只在对象可能被外部提前销毁且你要长期观察时使用。

练习：打印父对象的 children 数量，主动销毁一个堆子对象再观察。验收：能画出计数器窗口的对象树，并说明哪些成员是所有者、哪些是观察者。 参考：QObject。
