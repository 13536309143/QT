从第一个窗口开始，逐步学会独立开发

本课程面向刚接触 Qt 的学习者，环境为 Qt 6.8.3 / MSVC 2022 / C++17。 共 67 章、18 个可编译示例、1 个 TaskDesk 综合项目、21 个逐步实验。

选择你的起点

  • 第一次写 C++：先读零基础预备课，再学习工具、环境和首个窗口。
  • 学过 C++，第一次用 Qt：从学习地图开始，按下方各阶段推进。
  • 想用 Qt Creator 图形操作：从 Creator 工作区入门，跟着完成 Kit、Designer、信号槽和调试练习；第 02 章后即可提前学习。
  • 已有入门经验：选择 异步任务、模型进阶、测试进阶 补齐薄弱环节。
  • 学习图形集成：从 图形预备课 开始，再学习 OpenGL 与 Vulkan；图形自检需要正常桌面与驱动，Vulkan 为可选构建。

每课先理解输入、输出和对象寿命，再运行原例，修改一个功能，验证正常、边界、失败三条路径。 全书从 00 到 66 连续编号，章节文件名、侧栏与“上一课 / 下一课”均采用同一顺序。每个主要函数的参数、结果与时机可查 函数详解手册。

完成第一个小目标

  1. 阅读项目 README 的环境要求，运行根目录 build.cmd。
  2. 在项目根目录运行 scripts\run.cmd 01_hello。
  3. 修改 examples/01_hello/main.cpp 的标题，重新构建并确认变化。

遇到问题看 新手答疑，想跟着操作看 逐步实操实验。
