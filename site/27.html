27 · 多线程：后台任务、取消和退出

先确定为什么要线程

网络本身通常可异步完成，不必每个 HTTP 请求都开线程。CPU 密集计算、阻塞式第三方库和大量解析才常需要后台执行。QWidget 只能在 GUI 线程使用，后台完成结果通过信号传回来。

QThread 对象通常活在创建它的线程，而 run 管理的是另一个执行线程。把 Worker QObject moveToThread 后，它的槽才会按连接类型在对应线程运行。带父对象的 Worker 不能直接搬到另一个线程；示例先创建无父 Worker，再移动。

阅读 08_worker 的退出路径

start 创建 Worker；started 触发 run；progress 排队更新进度条；finished 请求线程退出；thread finished 安排 Worker 删除。窗口析构时先 requestInterruption，再 quit 和 wait，确保线程不会带着仍被使用的对象离开。

本例 finished → thread.quit 使用 DirectConnection 是有意的：quit 是线程安全的退出请求，不是 GUI 更新。关闭窗口时 GUI 线程可能正在 wait，不能依赖排队到 GUI 线程的 quit 才让后台结束。这个特例不能推广到任意对象方法。

取消是协作行为

requestInterruption 只是标记，后台必须定期检查。长时间阻塞 I/O 还需要超时或可取消 API。若把 cancel 槽排队到一个正在执行长循环的 Worker，那个槽可能要等循环结束才处理，因此示例直接用线程安全的中断请求。

不要使用 terminate 强行杀线程，资源可能无法正常释放。示例线程每 20ms 检查一次，关闭等待短；实际程序应设计有界退出策略。共享可变数据才需要 QMutex 等同步；优先通过消息传值减少共享。练习：开始、取消、再次开始，然后运行中关闭窗口。验收：没有 QThread destroyed while running，没有跨线程控件警告。 参考：线程与 QObject。

配套完整源码

在根工程构建本章目标：08_worker。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QtWidgets>
class Worker : public QObject {
    Q_OBJECT
public slots:
    void run() {
        for(int i=0;i<=100;++i) {
            if(QThread::currentThread()->isInterruptionRequested()) break;
            QThread::msleep(20); // 仅模拟后台耗时工作，不在 GUI 线程 sleep
            emit progress(i);
        }
        emit finished();
    }
signals: void progress(int value); void finished();
};
class Window : public QWidget {
public:
    Window() {
        auto *layout=new QVBoxLayout(this); auto *bar=new QProgressBar(this);
        auto *start=new QPushButton(QStringLiteral("开始"),this);
        auto *cancel=new QPushButton(QStringLiteral("取消"),this);
        layout->addWidget(bar); layout->addWidget(start); layout->addWidget(cancel);
        connect(start,&QPushButton::clicked,this,[=] {
            if(thread_.isRunning()) return;
            bar->setValue(0); start->setEnabled(false);
            auto *worker=new Worker; worker->moveToThread(&thread_);
            connect(&thread_,&QThread::started,worker,&Worker::run);
            connect(worker,&Worker::progress,bar,&QProgressBar::setValue);
            connect(worker,&Worker::finished,&thread_,&QThread::quit,Qt::DirectConnection);
            connect(&thread_,&QThread::finished,worker,&QObject::deleteLater);
            thread_.start();
        });
        connect(&thread_,&QThread::finished,this,[=] { start->setEnabled(true); });
        connect(cancel,&QPushButton::clicked,this,[this] { thread_.requestInterruption(); });
    }
    ~Window() override { thread_.requestInterruption(); thread_.quit(); thread_.wait(); }
private: QThread thread_;
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); Window w; w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
#include "main.moc"
