48 · 新手答疑、术语表与阶段自测

开始学习时最常见的疑问

必须先学完 C++ 吗？ 不必先掌握所有高级语法，但至少要读懂判断、循环、函数、类、指针与基本生命周期。读不懂 main.cpp 时回到第 01、04、05 章，自己推演变量变化，再继续信号槽。

先学 Widgets 还是 QML？ 本课程以桌面工具为目标，先用 Widgets 学 C++ 对象、布局和事件，再用 QML 学绑定与组件。已有移动端或动画需求可以提前阅读 QML，但 C++ 与线程基础仍要补齐。

Qt Creator 和 Designer 一样吗？ Creator 是开发环境，Designer 是设计 Widgets 表单的工具；ui 文件需要 uic 转换并参与构建。拖出按钮不会自动完成保存文件和数据库业务。

为什么刚写完文件却没生效？ 依次检查是否保存、是否加入 CMake 目标、是否构建成功、是否运行了正确配置的 exe。不要先从网上下载 DLL 覆盖 SDK。

会显示窗口就算学会了吗？ 还要检查错误、取消、重复点击、后台运行时关闭、排序后操作对象是否正确。每个功能至少写正常、边界、失败三种情形。

阶段自测与回退路线

  1. 入门：不看答案从空目录写 QApplication + QLabel，解释 app.exec。失败回读 06、07。
  2. 交互：为表单加复位和校验，不使用固定坐标，不产生两份不一致状态。失败回读 09、10、11。
  3. 数据：排序后删除选中任务，证明删除的是业务主键；取消保存不丢内容。失败回读 18、22。
  4. 异步：模拟 A 慢 B 快，界面始终显示 B；关闭时任务正确结束。失败回读 27、28。
  5. 工程：写一条会抓住真实缺陷的测试，再生成可独立启动的 dist。失败回读 36、37、40。

参考答案不要求逐字相同，要求能解释所有权、数据流与失败策略。连续两次只会照抄时，缩小目标到一个按钮、一个状态和一个日志，先完成一个可解释的闭环。

函数和图形专题继续阅读

想了解调用细节时，先在 函数详解手册 按对象类型查参数、返回值和失败处理，再回到对应章节的源码。手册中同名函数要结合所属类理解，自定义 Counter、TaskStore、LineProtocol 以课程实现为准。

图形从 第 49 章 按序学习：预备知识 → OpenGL 上下文与三角形 → 矩阵、纹理和调试 → Vulkan 环境与清屏 → 管线、显存与同步 → 集成与发布。先跑通基础示例，再完成明确标注的扩展实验，不把验证范围以外的效果当作已经实现。

学习日志模板（记录方式）

每次记录：今天完成的目标；修改的文件；正常/边界/失败验证结果；尚未理解的一件事；下次准备做的最小改动。每周从已运行的代码中选一段，合上教程独立重写，再解释不同写法的取舍。
