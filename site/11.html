前置：信号槽、布局。配套：14_controls。目标：让控件围绕同一份状态工作。

根据数据选择控件

需求 控件 读取值 常用通知
一行文字 QLineEdit text() textChanged / textEdited
整数范围 QSpinBox value() valueChanged
固定选项 QComboBox currentData() currentIndexChanged
是否启用 QCheckBox isChecked() toggled
多选一 QRadioButton + QButtonGroup checkedId() idClicked
大段纯文本 QPlainTextEdit toPlainText() textChanged

下拉框的展示文字会翻译或改名，业务逻辑宜使用 itemData 中的稳定值。不要用显示的“高级”字符串作为数据库编码，也不要假定第 2 个选项永远代表同一业务含义。

程序设置与用户编辑

QLineEdit 的 textChanged 在程序 setText 时也可能发出；textEdited 面向用户编辑。类似地，currentIndexChanged 包括程序修改，activated 用于用户激活选项。选择通知前先明确：你在同步显示，还是要响应一次用户提交？保存文件、发网络请求等操作通常不应绑在每一次文字变化上。

示例将滑块和数字框互相连接。setValue 的值不变时不会不断发 valueChanged，因此不会无限递归。但这不意味着所有双向连接都安全；两个方向分别做取整或单位换算时，仍可能振荡。更复杂时应让业务状态居中，控件只读取和提交。

批量重置避免半成品显示

QSignalBlocker 在作用域内暂停对象通知，离开作用域后恢复原先状态。它不会把阻止过的信号排队补发，也不负责修改数据。因此示例同时更新四个控件，并在最后显式刷新预览。

不要在打开阻塞器后销毁被阻塞对象；也不要用它掩盖数据循环依赖。优先使状态更新只有一个明确入口。

跟着做

  1. 构建并运行 scripts\run.cmd 14_controls，拖动滑块，观察数字框和预览同步。
  2. 输入中文姓名、空格，确认预览采用 trimmed 后的值。
  3. 在下拉框添加“独立写过程序”，把业务值设为 2。
  4. 把默认时间改成 45，检查初始化和恢复默认是否一致。
  5. 用 Tab 操作全部输入项，再按 Alt+N 检查标签快捷键。

验收：两种时间输入始终一致；恢复默认后全部状态正确；改变选项展示名称不改变业务值。练习答案要点：从 currentData 获取编号，预览文字由状态生成，不能再反向解析预览找数值。

参考：QLineEdit、QSignalBlocker。

配套完整源码

在根工程构建本章目标：14_controls。运行 scripts\run.cmd 14_controls。

main.cpp

#include <QtWidgets>

int main(int argc, char **argv) {
    QApplication app(argc, argv);
    QWidget window;
    window.setWindowTitle(QStringLiteral("14 · 控件与状态同步"));
    auto *layout = new QFormLayout(&window);
    auto *name = new QLineEdit(&window);
    name->setObjectName("nameInput");
    name->setMaxLength(40);
    auto *level = new QComboBox(&window);
    level->addItem(QStringLiteral("刚开始"), 0);
    level->addItem(QStringLiteral("学过 C++"), 1);
    auto *minutes = new QSpinBox(&window);
    minutes->setRange(5, 120);
    minutes->setValue(30);
    auto *slider = new QSlider(Qt::Horizontal, &window);
    slider->setRange(5, 120);
    slider->setValue(30);
    auto *preview = new QLabel(&window);
    preview->setObjectName("preview");
    preview->setWordWrap(true);
    auto *reset = new QPushButton(QStringLiteral("恢复默认"), &window);
    layout->addRow(QStringLiteral("姓名(&N)"), name);
    layout->addRow(QStringLiteral("基础(&L)"), level);
    layout->addRow(QStringLiteral("每天分钟数(&M)"), minutes);
    layout->addRow(QStringLiteral("拖动调整"), slider);
    layout->addRow(preview);
    layout->addRow(reset);
    QObject::connect(slider, &QSlider::valueChanged, minutes, &QSpinBox::setValue);
    QObject::connect(minutes, &QSpinBox::valueChanged, slider, &QSlider::setValue);
    auto refresh = [=] {
        const QString who = name->text().trimmed();
        preview->setText(QStringLiteral("%1：%2，每天 %3 分钟")
            .arg(who.isEmpty() ? QStringLiteral("未填写姓名") : who)
            .arg(level->currentText()).arg(minutes->value()));
    };
    QObject::connect(name, &QLineEdit::textChanged, &window, refresh);
    QObject::connect(level, &QComboBox::currentIndexChanged, &window, refresh);
    QObject::connect(minutes, &QSpinBox::valueChanged, &window, refresh);
    QObject::connect(reset, &QPushButton::clicked, &window, [=] {
        // 批量修改时暂停中间通知，最后统一刷新派生显示。
        const QSignalBlocker blockName(name), blockLevel(level), blockMinutes(minutes), blockSlider(slider);
        name->clear(); level->setCurrentIndex(0);
        minutes->setValue(30); slider->setValue(30);
        refresh();
    });
    refresh();
    window.resize(520, 280);
    window.show();
    if (app.arguments().contains("--smoke")) QTimer::singleShot(150, &app, &QCoreApplication::quit);
    return app.exec();
}

输入、选择与表单：参数、结果与时机

QLineEdit::text()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回当前 QString 文本副本。
  • 调用时机与易错点：读取不会自动 trimmed 或校验；空白字符串可能仍非空。

QLineEdit::setText(text)

  • 参数怎样填：新的 QString。
  • 作用与返回结果：替换输入内容，可能发出 textChanged。
  • 调用时机与易错点：程序设置不等于用户编辑，区别 textEdited；必要时防止保存动作被同步通知触发。

setPlaceholderText(text)

  • 参数怎样填：空输入时的提示文本。
  • 作用与返回结果：设置占位提示，返回 void。
  • 调用时机与易错点：不是默认值；text() 仍可能为空。

setMaxLength(length)

  • 参数怎样填：int，输入长度上限。
  • 作用与返回结果：限制 QLineEdit 文本长度。
  • 调用时机与易错点：业务层仍需验证；字符长度和 UTF-8 协议字节数不是同一单位。

QSpinBox::setRange(min, max)

  • 参数怎样填：最小与最大 int。
  • 作用与返回结果：设置合法输入区间，当前值可能随之被调整。
  • 调用时机与易错点：先设范围，再设默认值；不要用它代替仓储边界验证。

QSpinBox::value() / setValue(value)

  • 参数怎样填：读取无参数，写入 int。
  • 作用与返回结果：读取返回 int；写入返回 void，值变化时发 valueChanged。
  • 调用时机与易错点：设置与当前相同的值不持续制造变化，所以简单双向同步可终止。

QCheckBox::isChecked()

  • 参数怎样填：无参数。
  • 作用与返回结果：返回 bool 选中状态。
  • 调用时机与易错点：三态复选框需要更细状态时读取 checkState，不能把所有状态压成同一个 bool。

QComboBox::addItem(text, data)

  • 参数怎样填：展示文字与 QVariant 业务值。
  • 作用与返回结果：追加选项，返回 void。
  • 调用时机与易错点：名称可翻译；稳定业务编号放 data，不依赖展示文本。

currentText() / currentData()

  • 参数怎样填：无参数，currentData 可指定 role。
  • 作用与返回结果：分别返回展示 QString 与业务 QVariant。
  • 调用时机与易错点：没有合法当前项时要处理空值；编号不是当前索引的必然同义词。

setCurrentIndex(index)

  • 参数怎样填：int，下标从 0 开始。
  • 作用与返回结果：切换选项，可触发 currentIndexChanged。
  • 调用时机与易错点：程序修改也会触发；用户意图可根据需求选择 activated。

QLabel::setText(text)

  • 参数怎样填：新的显示文字。
  • 作用与返回结果：更新标签内容并请求重绘。
  • 调用时机与易错点：只改标签不等于改了业务计数。先更新唯一状态再刷新显示。

setWordWrap(enabled)

  • 参数怎样填：bool。
  • 作用与返回结果：使标签按可用宽度换行。
  • 调用时机与易错点：不解决所有布局约束；仍要检查长路径与缩放。

setEnabled(enabled)

  • 参数怎样填：bool。
  • 作用与返回结果：启用或禁用交互。
  • 调用时机与易错点：禁用按钮不能替代业务函数内部的“任务已运行”检查。

QSignalBlocker(object)

  • 参数怎样填：暂时阻止发信号的 QObject 指针。
  • 作用与返回结果：RAII 对象恢复进入作用域前的阻塞状态。
  • 调用时机与易错点：阻止过的信号不会离开作用域后补发；批量改完需明确刷新派生界面。
