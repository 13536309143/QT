22 · SQLite：连接、SQL、绑定和事务

一个数据库文件的结构

SQLite 不需要单独数据库服务，适合本地工具。QSqlDatabase 管理连接，QSqlQuery 执行 SQL，QSqlError 解释失败。驱动 QSQLITE 是 Qt 插件，开发机运行正常但分发后失败时应检查 sqldrivers 插件部署。

运行 10_sql，数据库使用 :memory:，退出即消失。CREATE TABLE 创建结构，INSERT 插入记录，SELECT 返回行，query.next 才把游标移动到结果。不能在 next 之前直接 value 获取第一行。

一律绑定外部数据

query.prepare("INSERT INTO tasks(title) VALUES(:title)");
query.bindValue(":title", title);
if (!query.exec()) { /* 显示 query.lastError().text() */ }

不要用字符串拼接标题到 SQL。绑定解决引号转义并隔离数据与 SQL 语句结构。表名、列名不能用普通值占位符替代，动态列名应从固定白名单选择。

事务和连接生命期

多条操作需要一起成功时，先 transaction，任意一步失败 rollback，全部成功 commit，并检查三个阶段结果。连接只能在满足 Qt 线程规则的线程使用，后台数据库工作应创建自己的连接；不能复制 QSqlDatabase 句柄就当作线程隔离。

removeDatabase 前必须销毁相关 query/model 和句柄。TaskStore 析构先关闭连接，清空自身句柄，再移除命名连接；窗口在 Store 之前销毁，避免模型持有连接。应用扩展时不要让查询逃出仓储的有效范围。

练习：一次事务插入两条记录，故意让第二条违反约束，验证第一条也被回滚。验收：标题含单引号和中文仍正常；重复主键错误清楚可见。 参考：QSqlQuery。

配套完整源码

在根工程构建本章目标：10_sql。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QtCore>
#include <QtSql>
int main(int argc,char **argv) {
    QCoreApplication app(argc,argv);
    auto db=QSqlDatabase::addDatabase("QSQLITE"); db.setDatabaseName(":memory:");
    if(!db.open()) { qCritical()<<db.lastError().text(); return 1; }
    QSqlQuery query(db);
    if(!query.exec("CREATE TABLE tasks(id INTEGER PRIMARY KEY, title TEXT NOT NULL)")) return 2;
    query.prepare("INSERT INTO tasks(title) VALUES(:title)");
    query.bindValue(":title",QStringLiteral("带引号的任务 ' Qt"));
    if(!query.exec()) { qCritical()<<query.lastError().text(); return 3; }
    if(!query.exec("SELECT id,title FROM tasks ORDER BY id")) return 4;
    while(query.next()) qInfo()<<query.value(0).toInt()<<query.value(1).toString();
    return 0;
}
