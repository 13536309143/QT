07 · 信号与槽：把行为连接起来

从用户点击到状态改变

信号表示发生了某件事，槽或 lambda 响应它。以计数器为例：按钮 clicked → 计数加一 → 自定义 countChanged → 标签更新。让状态变化发信号，比把所有控件更新硬塞到点击函数里更容易扩展。

connect(button, &QPushButton::clicked, this, [this] {
    emit countChanged(++count_);
});

emit 只是表达“发出信号”的可读性标记。信号由 moc 提供实现，不要自己为同一个信号写函数体。新式函数指针连接能做编译期类型检查，初学时优先使用，不使用旧字符串 SIGNAL/SLOT 语法。

连接类型

AutoConnection 在发射时依据接收对象的线程归属选择直接或排队执行。同线程通常立即调用；跨线程通常排队到接收线程。DirectConnection 在发射线程执行槽，因此不能把后台信号强制 Direct 到界面更新槽。QueuedConnection 需要接收线程处理事件，参数必须可复制并且 Qt 元类型系统知道相应类型。避免把指向短生命周期缓冲区的裸指针作为排队消息。

常见问题

重复调用 connect 会导致一次点击执行多次。构造时集中连接，或保存 QMetaObject::Connection 以便精确断开。UniqueConnection 不能通用于 lambda 去重。信号槽参数不必完全一样，接收端可以不接收信号的尾部参数，但已接收的参数类型应兼容。

操作：运行 02_counter，增加“重置”按钮；重置应先改变 count_，再发同一个 countChanged。验收：加三次后重置显示 0，再加一次显示 1；不要只修改标签却忘了内部状态。 参考：信号槽。

配套完整源码

在根工程构建本章目标：02_counter。以下是仓库内同一份文件，修改请到 examples 目录。

main.cpp

#include <QtWidgets>
class Counter final : public QWidget {
    Q_OBJECT
public:
    Counter() {
        auto *layout = new QVBoxLayout(this);
        auto *value = new QLabel("0", this);
        auto *button = new QPushButton(QStringLiteral("加一"), this);
        layout->addWidget(value); layout->addWidget(button);
        // this 是连接上下文：窗口销毁后连接自动失效。
        connect(button, &QPushButton::clicked, this, [this] { emit countChanged(++count_); });
        connect(this, &Counter::countChanged, value, [value](int n) { value->setText(QString::number(n)); });
        resize(320,180);
    }
signals:
    void countChanged(int count);
private:
    int count_ = 0;
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); Counter w; w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
// Q_OBJECT 在 cpp 中定义时，AUTOMOC 需要这一行。
#include "main.moc"
