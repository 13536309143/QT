51 · OpenGL 三角形逐行讲解：着色器、VAO 与 VBO

一、先看完整数据布局

本章所有调用均对应 17_opengl。每个顶点是 x,y,r,g,b，位置为两个 float，颜色为三个 float。shader 使用 location=0 接位置，location=1 接颜色；两者共用一个缓冲。location 是接口编号，不是内存地址。

第一个顶点从第 0 字节开始，位置 offset=0；颜色在两个 float 之后，offset=8。下一顶点的位置距离当前顶点 5*sizeof(float)，因此 stride=20。把 stride 误写为 5 会按 5 字节读取，坐标和颜色都错。

二、顶点着色器每行做什么

#version 330 core
layout(location=0) in vec2 position;
layout(location=1) in vec3 color;
out vec3 vertexColor;
void main() {
    gl_Position = vec4(position, 0.0, 1.0);
    vertexColor = color;
}

version 指明 GLSL 版本和 profile。in 声明每个顶点从属性布局接收的数据；out 将颜色交给后续插值。gl_Position 是规定的齐次裁剪坐标，vec4 的 z=0、w=1 让本章先跳过透视。

三个顶点分别红、绿、蓝，三角形内部出现渐变，是光栅化阶段对 vertexColor 插值的结果，不是 CPU 给每个屏幕像素上传了一种颜色。

三、片元着色器怎样接上

#version 330 core
in vec3 vertexColor;
out vec4 fragmentColor;
void main() {
    fragmentColor = vec4(vertexColor, 1.0);
}

两阶段的接口类型必须匹配。alpha=1 表示不透明，但是否进行透明混合还取决于 GL 状态，单改 alpha 不保证看到后方物体。编译成功只证明单个 shader 合法，link 才检查组合接口。

四、program 的每个调用

函数 参数 返回值与检查 何时调用
addShaderFromSourceCode Vertex/Fragment 与源码 bool；失败读 log 初始化阶段
link 无参数 bool；失败停止绘制 两阶段添加成功后
bind 无参数 bool；激活该 program 配置属性或绘制前
enableAttributeArray location void；启用指定输入 VAO 绑定后配置
setAttributeBuffer location、类型、偏移、分量数、跨度 void；描述缓冲如何解释 VBO 与 VAO 已绑定时
release 无参数 void；解除当前 program 本次使用结束后

不能忽略编译日志继续画，再把黑屏归因于 Qt。也不能假设初始化时 bind 过 program，以后每次 paintGL 都永远保持当前状态。

五、VAO 与 VBO 分别存什么

QOpenGLBuffer::create 建立 GPU buffer handle，返回 bool；bind 激活目标绑定，返回 bool；setUsagePattern(StaticDraw) 是用途提示；allocate(data, byteCount) 上传初始内容，长度单位是字节，不是元素数。release 解除绑定，不是销毁；destroy 才释放对应资源。

VAO 保存顶点属性配置及相关绑定关系，不保存顶点数组的所有数据。QOpenGLVertexArrayObject::Binder 用作用域管理绑定，让函数结束时恢复解绑。Core profile 绘制需要有效的 VAO，不能照搬旧教程中“直接传一个 CPU 指针就行”的假设。

本例按顺序：创建 VAO/VBO → 绑定 VAO → 绑定 VBO → 上传数组 → 绑定 program → 配置两种属性 → 解绑。之后绘制时只需重新绑定 program 和 VAO，不必重复描述全部属性。

六、真正触发绘制

glClearColor 的四个 float 设置清除颜色；glClear 用位标志决定清哪些缓冲。二者不会自动生成三角形。glDrawArrays(GL_TRIANGLES,0,3) 从第 0 个顶点开始，使用 3 个顶点组成一个三角形，最后一个参数不是“3 字节”或“三个三角形”。

本例没有索引缓冲，因此不是 glDrawElements。以后共享顶点时再加 EBO，索引类型、索引数量和顶点跨度应分别检查。GPU 调用通常先进入命令队列，不要把函数返回当作图像已显示。

七、故障实验

  1. 将颜色 offset 改为 0，预测颜色将来自什么数据；运行后恢复。
  2. 将 glDrawArrays 的数量改为 0，应只剩背景；自检应失败。
  3. 故意把 vertexColor 的类型在两阶段写成不同类型，检查 link 日志。
  4. 将三个颜色都改成黄色，确认这是数据改变，不需要修改片元算法。

验收：能独立写出两条 setAttributeBuffer，并说明每个参数的单位与来源。下一章再引入矩阵和纹理，不在尚未理解 buffer 时直接复制大型 3D 引擎。
