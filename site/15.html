15 · Qt Designer：可视化设计和 ui 文件

.ui 文件如何变成界面

Designer 保存的是 XML 描述，uic 在构建时生成 ui_form.h。Ui::Form ui; ui.setupUi(&window); 创建控件与布局，把生成的指针保存在 ui 对象里。不要修改生成的头文件，因为下次构建会覆盖它。

从现有表单开始

  1. 用 SDK 中的 bin/designer.exe 或 Qt Creator 设计模式打开 examples/11_designer/form.ui。
  2. 选中 QLineEdit，在属性面板查看 objectName 为 lineEdit；给它设置 placeholderText。
  3. 选中顶层窗口并确认已经安装垂直布局，拉伸画布检查适配。
  4. 设置 Tab 顺序，使键盘输入可以从文本框移动到按钮。
  5. 保存，重新编译 11_designer。源码里的 ui.lineEdit 名称要与 objectName 一致。

把业务规则写在自己维护的 cpp 文件，而不是 ui 文件。自动命名槽 on_object_signal 很方便，但改 objectName 时容易发生隐式失效；本课程采用显式 connect，让连接关系可搜索。

本例 ui 是 main 中的局部变量，在 app.exec 返回前一直存在，因此 lambda 引用它是有效的。如果把 setupUi 放在一个很快返回的辅助函数里，再捕获这个局部 ui 的引用，就会悬空。正式窗口类通常将 Ui::Form 放在成员或使用 unique_ptr 管理。

练习：加一个清空按钮和一行说明，重建后验证键盘 Tab 与鼠标都能使用。验收：提交 ui 源文件，忽略生成头；Designer 预览和真实运行的布局一致。

配套完整源码

在根工程构建本章目标：11_designer。以下是仓库内同一份文件，修改请到 examples 目录。

form.ui

<?xml version="1.0" encoding="UTF-8"?>
<ui version="4.0"><class>Form</class><widget class="QWidget" name="Form">
<property name="windowTitle"><string>Designer 表单</string></property>
<layout class="QVBoxLayout" name="verticalLayout">
<item><widget class="QLineEdit" name="lineEdit"><property name="placeholderText"><string>输入你的名字</string></property></widget></item>
<item><widget class="QPushButton" name="pushButton"><property name="text"><string>问候</string></property></widget></item>
<item><widget class="QLabel" name="label"><property name="text"><string>等待输入</string></property></widget></item>
</layout></widget><resources/><connections/></ui>

main.cpp

#include <QtWidgets>
#include "ui_form.h"
int main(int argc,char **argv) {
    QApplication app(argc,argv); QWidget w; Ui::Form ui; ui.setupUi(&w);
    QObject::connect(ui.pushButton,&QPushButton::clicked,&w,[&ui] {
        ui.label->setText(QStringLiteral("你好，%1").arg(ui.lineEdit->text().trimmed()));
    });
    w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
