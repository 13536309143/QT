# 21 · Model/View：列表与表格的核心

## 数据与展示分开
QTableView 展示数据，QAbstractTableModel 提供数据，QStyledItemDelegate 决定绘制和编辑。简易原型可用 QTableWidget，但数据规模、复用或业务规则变复杂后，自定义模型更清楚。不要为表格每个单元格都创建 QWidget 来显示简单文本。

必须实现 rowCount、columnCount、data。表模型的有效父索引通常返回 0，因为它不是树。QModelIndex 标识某个模型中的位置，不是永久数据库主键。删除、排序和重置后索引可能失效。

data 通过 role 返回不同信息：DisplayRole 显示文本，EditRole 编辑值，CheckStateRole 勾选状态，UserRole 可存业务标识。不要在 data 内进行网络请求或昂贵数据库操作，因为视图会频繁调用它。

## 编辑与通知
flags 声明可编辑，setData 校验并更新存储，再发 dataChanged。新增行必须在修改容器前 beginInsertRows、修改后 endInsertRows；删行使用对应 remove 通知。全量替换数据用 beginResetModel/endResetModel，但不要为了省事把每次单格修改都变成整表重置。

运行 06_model，双击任务名修改；输入空白会被拒绝。当前例子的优先级是演示字符串，排序也采用字符串规则。若改成数值优先级，应在模型中保存整数并返回对应 QVariant，避免 10 排在 2 前面。

练习：新增“添加行”按钮，正确通知视图。验收：新行立即出现，选择不会随机跳动；空值被拒绝，通知的索引范围合法。
参考：[Model/View](https://doc.qt.io/qt-6.8/model-view-programming.html)。

## 配套完整源码

在根工程构建本章目标：`06_model`。以下是仓库内同一份文件，修改请到 examples 目录。

### main.cpp

```cpp
#include <QtWidgets>
class TaskModel : public QAbstractTableModel {
public:
    using QAbstractTableModel::QAbstractTableModel;
    int rowCount(const QModelIndex &parent={}) const override { return parent.isValid()?0:rows_.size(); }
    int columnCount(const QModelIndex &parent={}) const override { return parent.isValid()?0:2; }
    QVariant data(const QModelIndex &index,int role=Qt::DisplayRole) const override {
        if(!index.isValid() || index.row()<0 || index.row()>=rows_.size() || index.column()<0 || index.column()>1) return {};
        if(role==Qt::DisplayRole || role==Qt::EditRole) return rows_[index.row()][index.column()];
        return {};
    }
    QVariant headerData(int section,Qt::Orientation orientation,int role) const override {
        if(orientation==Qt::Horizontal && role==Qt::DisplayRole)
            return section==0?QStringLiteral("任务"):QStringLiteral("优先级");
        return QAbstractTableModel::headerData(section,orientation,role);
    }
    Qt::ItemFlags flags(const QModelIndex &index) const override {
        return index.isValid()?QAbstractTableModel::flags(index)|Qt::ItemIsEditable:Qt::NoItemFlags;
    }
    bool setData(const QModelIndex &index,const QVariant &value,int role) override {
        if(role!=Qt::EditRole || !index.isValid() || index.row()<0 || index.row()>=rows_.size() || index.column()<0 || index.column()>1) return false;
        const auto text=value.toString().trimmed(); if(text.isEmpty()) return false;
        rows_[index.row()][index.column()]=text; emit dataChanged(index,index,{Qt::DisplayRole,Qt::EditRole}); return true;
    }
private:
    QVector<QStringList> rows_{{QStringLiteral("学习布局"),"1"},{QStringLiteral("学习模型"),"2"}};
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); QWidget w; auto *layout=new QVBoxLayout(&w);
    auto *search=new QLineEdit(&w); search->setPlaceholderText(QStringLiteral("按任务名过滤"));
    auto *table=new QTableView(&w); auto *model=new TaskModel(&w);
    auto *proxy=new QSortFilterProxyModel(&w); proxy->setSourceModel(model); proxy->setFilterKeyColumn(0);
    proxy->setFilterCaseSensitivity(Qt::CaseInsensitive); table->setModel(proxy); table->setSortingEnabled(true);
    QObject::connect(search,&QLineEdit::textChanged,proxy,&QSortFilterProxyModel::setFilterFixedString);
    layout->addWidget(search); layout->addWidget(table); w.resize(600,350); w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
```

## 模型、代理与索引：参数、结果与时机

### `rowCount(parent) / columnCount(parent)`

- **参数怎样填**：父索引，平面表格通常只接受无效父索引。
- **作用与返回结果**：返回该父节点下的行列数 int。
- **调用时机与易错点**：对于有效父索引，简单平面模型通常返回 0，避免被误判为树。

### `data(index, role)`

- **参数怎样填**：索引与所需角色，如 DisplayRole。
- **作用与返回结果**：返回 QVariant；不支持角色或非法位置返回空值。
- **调用时机与易错点**：显示、编辑、排序可读取不同角色，不能把所有角色都当字符串。

### `headerData(section, orientation, role)`

- **参数怎样填**：表头位置、方向和角色。
- **作用与返回结果**：返回对应表头 QVariant。
- **调用时机与易错点**：只处理自定义情形，其他请求交回基类，避免破坏默认行号。

### `flags(index)`

- **参数怎样填**：索引。
- **作用与返回结果**：返回可选、启用、可编辑等标志位。
- **调用时机与易错点**：单独增加 ItemIsEditable 不会自动实现保存，还需 setData。

### `setData(index, value, role)`

- **参数怎样填**：目标、候选数据和编辑角色。
- **作用与返回结果**：返回 bool；成功更新数据后发 dataChanged。
- **调用时机与易错点**：先校验范围与类型，失败不改原数据；不要仅刷新文字而不更新模型。

### `dataChanged(topLeft, bottomRight, roles)`

- **参数怎样填**：受影响的矩形范围和角色列表。
- **作用与返回结果**：信号通知视图重新读取对应数据。
- **调用时机与易错点**：不是让数据自动改变；需先更新内部状态，再发通知。

### `beginInsertRows(parent, first, last) / endInsertRows()`

- **参数怎样填**：插入范围，first/last 包括两端。
- **作用与返回结果**：在修改容器前后成对通知视图。
- **调用时机与易错点**：begin 在旧结构仍有效时调用；不能修改完才通知开始。

### `setSourceModel(model) / setModel(model)`

- **参数怎样填**：分别属于代理模型和视图。
- **作用与返回结果**：连接源数据到代理、代理到视图。
- **调用时机与易错点**：视图不因此任意接管模型所有权，应明确 parent 或普通对象寿命。

### `setFilterKeyColumn(column)`

- **参数怎样填**：待筛选的列号；-1 有其多列语义。
- **作用与返回结果**：设置筛选列。
- **调用时机与易错点**：本例任务标题在第 0 列，选错列会让查询结果看似丢失。

### `setFilterFixedString(text)`

- **参数怎样填**：用户筛选文字。
- **作用与返回结果**：按固定字符串规则过滤。
- **调用时机与易错点**：与正则表达式筛选不同，用户输入正则符号不会自动成为模式。

### `mapToSource(proxyIndex)`

- **参数怎样填**：当前代理索引。
- **作用与返回结果**：返回源模型索引。
- **调用时机与易错点**：删除和更新先检查有效性，再读稳定主键；代理行号不是数据库 id。

### `currentIndex() / isValid()`

- **参数怎样填**：视图取当前项，索引检查有效性。
- **作用与返回结果**：返回 QModelIndex / bool。
- **调用时机与易错点**：没有选中或模型已 reset 时旧索引可能无效，不能继续读取旧行。

### `setSortingEnabled(true)`

- **参数怎样填**：视图 bool。
- **作用与返回结果**：允许表头触发排序。
- **调用时机与易错点**：字典序的字符串“10”可能先于“2”，数值排序要提供合适类型或角色。
