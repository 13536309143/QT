# 10 · 布局管理：让界面适应窗口

## 不要依赖绝对坐标
手工设置每个控件的 x、y、width、height，在字体放大、窗口缩放和翻译后很容易重叠。QVBoxLayout 垂直排列，QHBoxLayout 水平排列，QGridLayout 按行列组织，QFormLayout 组织标签与输入框。复杂界面通过嵌套布局组合。

布局根据控件 minimumSize、sizeHint、sizePolicy、stretch 分配空间。sizeHint 是建议，不是强制尺寸。Stretch 是可分配额外空间时的相对权重；它不是像素，也不能覆盖所有最小尺寸约束。表单输入框一般希望水平扩展，操作按钮通常保持合理宽度。
```cpp
auto *row = new QHBoxLayout;
row->addWidget(search, 1);
row->addWidget(button, 0);
auto *page = new QVBoxLayout(parent);
page->addLayout(row);
page->addWidget(table, 1);
```
一个 QWidget 只能安装一个顶层布局。QMainWindow 已有自己的整体布局，不要直接给它 setLayout，应创建 centralWidget，再给 centralWidget 装布局。布局中加入另一个布局用 addLayout，加入控件用 addWidget。

## 动手检查
运行表单，把窗口从 420 宽拉到 900 宽，观察输入框的拉伸。给底部加入 addStretch，比较按钮是否仍会占满整个高度。设置合理 minimumSize，避免窗口缩到无法操作，而不是直接 setFixedSize 禁止全部缩放。

练习：上方搜索条、中间列表、下方三个按钮，要求列表吃掉大多数额外空间。验收：在 100% 和 150% 系统缩放下文本可读、按钮不挤压输入框。若没有第二种缩放环境，至少更改应用字体进行模拟，并记录尚未实测的条件。
参考：[布局管理](https://doc.qt.io/qt-6.8/layout.html)。

## 从纸上草图一步步搭界面

先画三块：搜索条、结果区、操作条。搜索条用 QHBoxLayout，输入框 stretch 为 1、按钮为 0；结果区放列表；最外层 QVBoxLayout 给结果区 stretch 为 1。操作条末尾 addStretch 可把按钮留在左侧，开头 addStretch 则推向右侧。

QSizePolicy::Expanding 表示愿意获得额外空间，不等于强制占满；minimumSize 是下限，setFixedWidth 会同时限制最小与最大宽度。多个约束冲突时，先检查固定尺寸，再检查最小尺寸、策略和 stretch，最后才考虑手工 resize。

需要可滚动的长表单时使用 QScrollArea，设置 widgetResizable，并把表单安装在内部内容 QWidget；不要直接对布局调用 setWidget。需要用户拖动左右面板比例时选 QSplitter，切换不同页面选 QStackedWidget 或 QTabWidget，不用手工反复隐藏大量零散控件模拟页面。

练习：在 03_form 增加一个只读说明面板，窗口缩小时允许滚动，放大时输入框扩展。用长中文标签与较大字体检查；验收时明确哪些控件扩展、哪些保持建议尺寸，并能解释原因。

## 布局与尺寸：参数、结果与时机

### `QVBoxLayout(parent)`

- **参数怎样填**：父 QWidget 或无父布局。
- **作用与返回结果**：创建纵向排列的布局。
- **调用时机与易错点**：带 QWidget 参数时安装为该控件的顶层布局，不给同一窗口安装第二个顶层布局。

### `addWidget(widget, stretch)`

- **参数怎样填**：控件指针和额外空间分配权重。
- **作用与返回结果**：加入布局，返回 void。
- **调用时机与易错点**：stretch 不是像素或百分比，受最小尺寸与 sizePolicy 约束。

### `addLayout(layout, stretch)`

- **参数怎样填**：子布局与拉伸权重。
- **作用与返回结果**：组成嵌套布局。
- **调用时机与易错点**：布局不是 QWidget，不能把任意布局直接传 addWidget。

### `addStretch(stretch)`

- **参数怎样填**：默认权重为 0，也可指定正权重。
- **作用与返回结果**：加入可伸展空白项。
- **调用时机与易错点**：用来推动控件位置，不负责存储和验证业务数据。

### `QFormLayout::addRow(label, field)`

- **参数怎样填**：标签文本和输入控件，或单个跨行控件。
- **作用与返回结果**：创建表单行；字符串标签重载会建立合适的 buddy。
- **调用时机与易错点**：它与 QVBoxLayout::addWidget 的用途不同，要先确认当前布局类型。

### `setMinimumSize(w, h)`

- **参数怎样填**：逻辑最小宽高。
- **作用与返回结果**：设置允许的尺寸下限。
- **调用时机与易错点**：不要用过大下限导致小屏窗口无法使用；需要长表单时考虑滚动区。

### `setSizePolicy(horizontal, vertical)`

- **参数怎样填**：QSizePolicy 枚举或策略对象。
- **作用与返回结果**：表达控件愿意怎样缩放。
- **调用时机与易错点**：这是布局协商信息，不强制覆盖其他尺寸约束。

**阅读任务**：在本章源码中找到上述实际出现的调用，给每个返回值标出检查位置；同组的扩展接口用于对照，不要求在当前示例中全部出现。结合 [完整函数手册](API.md#layout) 继续查阅。
