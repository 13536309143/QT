# 12 · 表单、输入验证和对话框

## 选择合适控件
单行文本用 QLineEdit，多行纯文本可用 QPlainTextEdit，富文本用 QTextEdit。有限整数选 QSpinBox，日期用 QDateEdit，固定集合选 QComboBox。让控件本身减少非法输入，比用户点击提交后收到十个错误更友好。

但控件限制不能代替业务校验。空白姓名应先 trimmed；年龄区间由业务决定；密码不要无必要地写入日志。QIntValidator 与 QRegularExpressionValidator 可帮助编辑过程约束，但 Intermediate 状态意味着用户还在输入，不能简单等同最终合法。

## 提交过程
读取输入 → 规范化 → 检查规则 → 执行业务 → 显示结果。失败时保留用户输入、聚焦相关控件、给出可采取行动的说明。课程示例用 QLabel 显示简短错误，避免每次敲键都弹出阻塞对话框。

QMessageBox 适合确认和简短提示；QFileDialog 用于选择路径；自定义 QDialog 用于复杂输入。`exec()` 运行模态对话框并引入嵌套事件循环；更复杂的异步程序可用 open 和 finished 信号。堆上创建的非模态对话框应明确父对象或设置关闭时删除，栈上创建后立即返回的对话框会消失。

练习：在 03_form 加入邮箱输入。暂只检查非空和一个 @，并在界面说明这是教学简化规则，不是完整邮箱校验。验收矩阵：空输入失败、全空格失败、未确认失败、正常姓名成功；修正后能直接再次提交。

进阶：把验证写成独立函数返回错误消息，界面只负责展示。这是后续业务层与界面层拆分的第一步。

## 配套完整源码

在根工程构建本章目标：`03_form`。以下是仓库内同一份文件，修改请到 examples 目录。

### main.cpp

```cpp
#include <QtWidgets>
int main(int argc,char **argv) {
    QApplication app(argc,argv); QWidget w;
    auto *layout = new QFormLayout(&w);
    auto *name = new QLineEdit(&w);
    auto *age = new QSpinBox(&w); age->setRange(1,120); age->setValue(18);
    auto *agree = new QCheckBox(QStringLiteral("确认信息正确"),&w);
    auto *submit = new QPushButton(QStringLiteral("提交"),&w);
    auto *result = new QLabel(&w); result->setWordWrap(true);
    layout->addRow(QStringLiteral("姓名"), name); layout->addRow(QStringLiteral("年龄"),age);
    layout->addRow(agree); layout->addRow(submit); layout->addRow(result);
    QObject::connect(submit,&QPushButton::clicked,&w,[=] {
        const auto text = name->text().trimmed();
        if(text.isEmpty() || !agree->isChecked()) {
            result->setText(QStringLiteral("请填写姓名并确认信息。")); return;
        }
        result->setText(QStringLiteral("你好，%1，你今年 %2 岁。").arg(text).arg(age->value()));
    });
    w.resize(420,250); w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
```

## 输入、选择与表单：参数、结果与时机

### `QLineEdit::text()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回当前 QString 文本副本。
- **调用时机与易错点**：读取不会自动 trimmed 或校验；空白字符串可能仍非空。

### `QLineEdit::setText(text)`

- **参数怎样填**：新的 QString。
- **作用与返回结果**：替换输入内容，可能发出 textChanged。
- **调用时机与易错点**：程序设置不等于用户编辑，区别 textEdited；必要时防止保存动作被同步通知触发。

### `setPlaceholderText(text)`

- **参数怎样填**：空输入时的提示文本。
- **作用与返回结果**：设置占位提示，返回 void。
- **调用时机与易错点**：不是默认值；text() 仍可能为空。

### `setMaxLength(length)`

- **参数怎样填**：int，输入长度上限。
- **作用与返回结果**：限制 QLineEdit 文本长度。
- **调用时机与易错点**：业务层仍需验证；字符长度和 UTF-8 协议字节数不是同一单位。

### `QSpinBox::setRange(min, max)`

- **参数怎样填**：最小与最大 int。
- **作用与返回结果**：设置合法输入区间，当前值可能随之被调整。
- **调用时机与易错点**：先设范围，再设默认值；不要用它代替仓储边界验证。

### `QSpinBox::value() / setValue(value)`

- **参数怎样填**：读取无参数，写入 int。
- **作用与返回结果**：读取返回 int；写入返回 void，值变化时发 valueChanged。
- **调用时机与易错点**：设置与当前相同的值不持续制造变化，所以简单双向同步可终止。

### `QCheckBox::isChecked()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回 bool 选中状态。
- **调用时机与易错点**：三态复选框需要更细状态时读取 checkState，不能把所有状态压成同一个 bool。

### `QComboBox::addItem(text, data)`

- **参数怎样填**：展示文字与 QVariant 业务值。
- **作用与返回结果**：追加选项，返回 void。
- **调用时机与易错点**：名称可翻译；稳定业务编号放 data，不依赖展示文本。

### `currentText() / currentData()`

- **参数怎样填**：无参数，currentData 可指定 role。
- **作用与返回结果**：分别返回展示 QString 与业务 QVariant。
- **调用时机与易错点**：没有合法当前项时要处理空值；编号不是当前索引的必然同义词。

### `setCurrentIndex(index)`

- **参数怎样填**：int，下标从 0 开始。
- **作用与返回结果**：切换选项，可触发 currentIndexChanged。
- **调用时机与易错点**：程序修改也会触发；用户意图可根据需求选择 activated。

### `QLabel::setText(text)`

- **参数怎样填**：新的显示文字。
- **作用与返回结果**：更新标签内容并请求重绘。
- **调用时机与易错点**：只改标签不等于改了业务计数。先更新唯一状态再刷新显示。

### `setWordWrap(enabled)`

- **参数怎样填**：bool。
- **作用与返回结果**：使标签按可用宽度换行。
- **调用时机与易错点**：不解决所有布局约束；仍要检查长路径与缩放。

### `setEnabled(enabled)`

- **参数怎样填**：bool。
- **作用与返回结果**：启用或禁用交互。
- **调用时机与易错点**：禁用按钮不能替代业务函数内部的“任务已运行”检查。

### `QSignalBlocker(object)`

- **参数怎样填**：暂时阻止发信号的 QObject 指针。
- **作用与返回结果**：RAII 对象恢复进入作用域前的阻塞状态。
- **调用时机与易错点**：阻止过的信号不会离开作用域后补发；批量改完需明确刷新派生界面。

**阅读任务**：在本章源码中找到上述实际出现的调用，给每个返回值标出检查位置；同组的扩展接口用于对照，不要求在当前示例中全部出现。结合 [完整函数手册](API.md#controls) 继续查阅。
