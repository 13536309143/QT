# 26 · QPainter：坐标、抗锯齿和仪表盘

## 绘图放在哪里
QWidget 的绘图写在 paintEvent，用 QPainter 绑定当前控件。状态改变时调用 update 安排重绘，由 Qt 合并多次请求。不要保存 QPainter 作为长期成员，也不要在按钮处理里直接拿它画完就以为图像永久存在。

本例用 translate 将原点移到中心，再 scale 把逻辑坐标映射到当前窗口。这样无论窗口大小，圆弧仍按相同比例绘制。抗锯齿让曲线边缘平滑，但会增加开销；一般仪表盘可启用，大量实时点则应先测量。

QPainter 角度采用 1/16 度，drawArc 的起始角和跨度方向要独立理解。示例不是医疗或工业仪表，仅用于练习动画与缩放。定时器每次改变 value_ 后 update，paintEvent 只读取状态绘制，不再启动定时器或修改业务数据。

## 高 DPI 和交互
Qt 6 默认具备高 DPI 支持。逻辑坐标与设备像素不是一回事；使用 QPixmap 离屏缓存时要考虑 devicePixelRatio。先采用矢量绘图和合理字体尺寸，比手工把每个坐标乘系统缩放更可靠。

练习：添加刻度、最小最大值和单位，窗口保持圆形而非拉成椭圆。验收：最小窗口中文字不与圆弧重叠；反复最小化和恢复图像仍完整。进阶：实现 setValue，只在数值实际变化时 update，并对 0~100 做边界处理。
参考：[绘图系统](https://doc.qt.io/qt-6.8/paintsystem.html)。

## 配套完整源码

在根工程构建本章目标：`07_paint`。以下是仓库内同一份文件，修改请到 examples 目录。

### main.cpp

```cpp
#include <QtWidgets>
#include <QtMath>
class Gauge : public QWidget {
public:
    Gauge() {
        auto *timer=new QTimer(this);
        connect(timer,&QTimer::timeout,this,[this] { value_=(value_+1)%101; update(); });
        timer->start(50); resize(420,320);
    }
protected:
    void paintEvent(QPaintEvent *) override {
        QPainter p(this); p.setRenderHint(QPainter::Antialiasing);
        const int side=qMin(width(),height());
        p.translate(width()/2.0,height()/2.0); p.scale(side/240.0,side/240.0);
        p.setPen(QPen(QColor("#334155"),12)); p.drawArc(QRectF(-90,-90,180,180),30*16,300*16);
        p.setPen(QPen(QColor("#16a085"),12)); p.drawArc(QRectF(-90,-90,180,180),210*16,-value_*3*16);
        p.setPen(palette().text().color()); QFont font=p.font(); font.setPixelSize(32); p.setFont(font);
        p.drawText(QRectF(-70,-30,140,60),Qt::AlignCenter,QString::number(value_));
    }
private: int value_=0;
};
int main(int argc,char **argv) {
    QApplication app(argc,argv); Gauge w; w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
```

## 绘图、事件与计时：参数、结果与时机

### `QTimer::start(interval) / stop()`

- **参数怎样填**：间隔毫秒或停止无参数。
- **作用与返回结果**：开始或停止 timeout 通知。
- **调用时机与易错点**：定时器必须在所属线程正确使用；不保证实时频率，GUI 忙时会延迟。

### `QWidget::update()`

- **参数怎样填**：无参数或更新区域。
- **作用与返回结果**：安排稍后的重绘请求，返回 void。
- **调用时机与易错点**：不是立即递归调用 paintEvent；多个请求可能合并，适合状态变化后使用。

### `paintEvent(event)`

- **参数怎样填**：Qt 传入 QPaintEvent 指针。
- **作用与返回结果**：由 QWidget 绘制调度调用，返回 void。
- **调用时机与易错点**：不要在构造函数里直接调用来替代事件系统；普通控件 QPainter 在此创建。

### `QPainter(this)`

- **参数怎样填**：绘制设备，这里是当前 QWidget。
- **作用与返回结果**：开始当前绘制过程，局部对象析构后结束。
- **调用时机与易错点**：只能在允许绘制的时机操作该设备，不保留跨事件的活动 painter。

### `setRenderHint(QPainter::Antialiasing)`

- **参数怎样填**：渲染提示与可选 bool。
- **作用与返回结果**：开启边缘抗锯齿。
- **调用时机与易错点**：改善边缘，不改变几何计算或解决低分辨率图片问题。

### `translate(x,y) / scale(sx,sy)`

- **参数怎样填**：平移距离或缩放比例。
- **作用与返回结果**：改变后续绘图的坐标变换。
- **调用时机与易错点**：顺序会改变结果；常先移到窗口中心，再缩放逻辑画布。

### `setPen(pen) / setFont(font)`

- **参数怎样填**：画笔与字体对象。
- **作用与返回结果**：设置后续绘图状态。
- **调用时机与易错点**：状态会继续影响后面的命令，局部修改可配 save/restore。

### `drawArc(rect, start, span)`

- **参数怎样填**：外接矩形、起角和跨度。
- **作用与返回结果**：绘制圆弧；Qt 角度单位为 1/16 度。
- **调用时机与易错点**：不是弧度；正负跨度影响方向，示例乘 16 是有意转换。

### `drawText(rect, flags, text)`

- **参数怎样填**：区域、对齐/布局标志和文字。
- **作用与返回结果**：在区域内绘制文本。
- **调用时机与易错点**：区域过小会裁切；设置字体后重新检查布局和缩放。

### `eventFilter(watched, event)`

- **参数怎样填**：被观察对象与事件指针。
- **作用与返回结果**：返回 true 表示过滤掉本次事件。
- **调用时机与易错点**：只处理明确条件，其他交给基类；检查 type 后才能安全转换具体事件类型。

### `QElapsedTimer::start() / elapsed()`

- **参数怎样填**：开始无参数，读取无参数。
- **作用与返回结果**：记录起点与经过的毫秒数。
- **调用时机与易错点**：用于测持续时间；日历时间与时区使用 QDateTime，不能混用。
