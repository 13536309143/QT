# 17 · QSettings 与应用路径：记住用户的选择

**前置**：第 16 章；路径与文件操作可结合第 18 章学习。**配套**：`15_settings`。**目标**：保存少量偏好，定位文件，并处理损坏值。

## 哪些内容适合保存在哪里

| 内容 | 推荐方式 | 原因 |
|---|---|---|
| 主题、语言、上次目录 | QSettings | 少量键值配置 |
| 大量任务与查询 | SQLite | 关系、事务和索引 |
| 可交换的数据 | JSON | 明确格式版本并校验 |
| 可重新生成的缓存 | CacheLocation | 不应当作唯一原始数据 |

QSettings 不等于加密保险箱，不保存明文密码和令牌。默认构造的 QSettings 依赖 organizationName、applicationName；Windows 原生格式可能使用注册表。示例故意使用显式 INI 路径，方便初学者观察，不需要猜注册表位置。

## 读值不是直接相信文件

```cpp
QSettings settings(path, QSettings::IniFormat);
bool ok = false;
int minutes = settings.value("study/minutes", 30).toInt(&ok);
if (!ok || minutes < 5 || minutes > 120) minutes = 30;
```

value 的第二个参数处理键不存在；`ok` 和范围判断处理“键存在但内容坏了”。示例还用 qBound 限制显示范围，练习时可改成上述严格回退策略，比较输入 abc、-100、999 的结果。

写入 setValue 后可以 sync，再检查 status，及时告知失败。多个字段的 QSettings 更新不能当作数据库事务；需要整组更新的原子性时改用事务数据库或明确的文件保存策略。

## 路径与工作目录

QStandardPaths 的 AppConfigLocation 返回当前应用适用的配置目录。先设定应用标识，再查询目录；用 QDir.mkpath 创建它，并处理失败。相对路径相对于进程的工作目录，不一定是 exe 目录，因此不要用 `./settings.ini` 假设它总在工程根目录。

程序安装目录可能不可写。saveGeometry/restoreGeometry 保存窗口几何状态；多显示器拔出、缩放改变等条件仍需要手工检查，不能只验证同一桌面重启。

## 实际操作

1. 运行 `scripts\run.cmd 15_settings`，记下界面显示的配置文件路径。
2. 填写姓名和时间，点击保存，再关闭重开。
3. 关闭程序后用文本编辑器将分钟数改成 999，观察边界策略。
4. 删除该示例的 INI 副本再重开，确认采用默认值；不要删除 TaskDesk 数据。
5. 实现“恢复默认但暂不保存”，取消退出后原配置仍保留。

验收：正常启动使用用户目录，--smoke 不改变真实配置；没有设置键时不崩溃；保存失败有提示。配置只会在点击“保存设置”时写入，关闭窗口本身不会自动保存本例的修改。

参考：[QSettings](https://doc.qt.io/qt-6.8/qsettings.html)、[QStandardPaths](https://doc.qt.io/qt-6.8/qstandardpaths.html)。

## 配套完整源码

在根工程构建本章目标：`15_settings`。运行 `scripts\run.cmd 15_settings`。

### main.cpp

```cpp
#include <QtWidgets>

int main(int argc, char **argv) {
    QApplication app(argc, argv);
    QCoreApplication::setOrganizationName("QtLearning");
    QCoreApplication::setApplicationName("SettingsLab");
    const bool smoke = app.arguments().contains("--smoke");
    QStandardPaths::setTestModeEnabled(smoke);
    QTemporaryDir temporary;
    const QString folder = smoke ? temporary.path() : QStandardPaths::writableLocation(QStandardPaths::AppConfigLocation);
    if (folder.isEmpty() || !QDir().mkpath(folder)) return 1;
    // 使用明确路径的 INI，便于观察；启动检查只写临时目录。
    QSettings settings(QDir(folder).filePath("preferences.ini"), QSettings::IniFormat);
    QWidget window;
    window.setWindowTitle(QStringLiteral("15 · 配置与恢复"));
    auto *layout = new QFormLayout(&window);
    auto *name = new QLineEdit(settings.value("profile/name", QString()).toString(), &window);
    auto *minutes = new QSpinBox(&window);
    minutes->setRange(5, 120);
    minutes->setValue(qBound(5, settings.value("study/minutes", 30).toInt(), 120));
    auto *save = new QPushButton(QStringLiteral("保存设置"), &window);
    auto *status = new QLabel(&window);
    status->setWordWrap(true);
    layout->addRow(QStringLiteral("姓名"), name);
    layout->addRow(QStringLiteral("每天分钟数"), minutes);
    layout->addRow(save);
    auto *pathLabel = new QLabel(QStringLiteral("配置文件：%1").arg(settings.fileName()), &window);
    pathLabel->setWordWrap(true);
    pathLabel->setTextInteractionFlags(Qt::TextSelectableByMouse);
    layout->addRow(pathLabel);
    layout->addRow(status);
    window.resize(620, 260);
    window.restoreGeometry(settings.value("window/geometry").toByteArray());
    QObject::connect(save, &QPushButton::clicked, &window, [&] {
        settings.setValue("profile/name", name->text().trimmed());
        settings.setValue("study/minutes", minutes->value());
        settings.setValue("window/geometry", window.saveGeometry());
        settings.sync();
        status->setText(settings.status() == QSettings::NoError
            ? QStringLiteral("已保存，请关闭后重新打开验证") : QStringLiteral("保存失败，请检查路径与权限"));
    });
    window.show();
    if (smoke) QTimer::singleShot(150, &app, &QCoreApplication::quit);
    return app.exec();
}
```

## 字符串、配置与文件：参数、结果与时机

### `QString::trimmed() / isEmpty()`

- **参数怎样填**：无参数。
- **作用与返回结果**：前者返回去首尾空白的新字符串；后者返回长度是否为 0。
- **调用时机与易错点**：trimmed 不原地修改；必须接收结果或继续链式调用。

### `QString::arg(value)`

- **参数怎样填**：占位符替换值，可链式调用。
- **作用与返回结果**：返回替换后的新 QString。
- **调用时机与易错点**：不是 SQL 参数绑定；需要控制小数格式时选择对应重载。

### `QString::toInt(ok, base)`

- **参数怎样填**：可传 bool 指针与进制，默认十进制。
- **作用与返回结果**：返回 int；通过 ok 区分真实 0 与解析失败。
- **调用时机与易错点**：不要直接相信失败时的默认数字，也要额外检查业务范围。

### `QString::toUtf8() / fromUtf8(bytes)`

- **参数怎样填**：前者无参数，后者接字节。
- **作用与返回结果**：在 Unicode 文本与 UTF-8 QByteArray 之间转换。
- **调用时机与易错点**：不要将半个多字节字符单独解码后拼接；协议先拆完整帧。

### `QString::size() / QByteArray::size()`

- **参数怎样填**：无参数。
- **作用与返回结果**：分别表示 UTF-16 代码单元数和字节数。
- **调用时机与易错点**：都不自动等于用户看到的字符数；接口限制必须写清单位。

### `QSettings::value(key, defaultValue)`

- **参数怎样填**：键名和键缺失时的默认 QVariant。
- **作用与返回结果**：返回 QVariant，可进一步检查转换结果。
- **调用时机与易错点**：默认值只处理缺失，不自动修复存在但内容损坏的值。

### `QSettings::setValue(key, value)`

- **参数怎样填**：键名与新值。
- **作用与返回结果**：记录配置更新，返回 void。
- **调用时机与易错点**：不是数据库事务或密码加密；多个字段的更新语义需自行设计。

### `QSettings::sync() / status()`

- **参数怎样填**：无参数。
- **作用与返回结果**：sync 同步存储；status 返回错误状态。
- **调用时机与易错点**：应在 sync 后检查状态并反馈保存失败，不能无条件显示成功。

### `QSettings::fileName()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回实际配置位置。
- **调用时机与易错点**：原生格式可能是注册表相关位置；本例选择显式 INI 便于观察。

### `QStandardPaths::writableLocation(type)`

- **参数怎样填**：如 AppConfigLocation 或 AppDataLocation。
- **作用与返回结果**：返回当前应用对应的可写位置 QString。
- **调用时机与易错点**：查询前设置应用标识，可能为空；返回目录不表示文件已创建。

### `QDir::mkpath(path)`

- **参数怎样填**：路径。
- **作用与返回结果**：返回 bool，递归创建目录或确认已存在。
- **调用时机与易错点**：失败需反馈，不能继续把写入错误解释成空数据。

### `QFile::open(mode)`

- **参数怎样填**：ReadOnly、WriteOnly 等打开模式。
- **作用与返回结果**：返回 bool，成功后才能 read/write。
- **调用时机与易错点**：文件不存在、权限、目录等都会导致失败，读取前检查。

### `QFile::readAll()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回剩余可读 QByteArray。
- **调用时机与易错点**：空内容与读取失败不同，还需 error()；大文件不要不设上限地一次全读。

### `QIODevice::write(bytes)`

- **参数怎样填**：要写入的 QByteArray。
- **作用与返回结果**：返回实际接受的字节数 qint64，-1 表示失败。
- **调用时机与易错点**：检查数值与目标长度；socket 接受不等于远端业务处理成功。

### `QSaveFile::commit()`

- **参数怎样填**：无参数。
- **作用与返回结果**：完成临时写入并替换目标，返回 bool。
- **调用时机与易错点**：只在写入完全成功后调用；失败不能更新文档路径或清除修改标记。

### `errorString()`

- **参数怎样填**：无参数；具体类如 QFile 或 socket。
- **作用与返回结果**：返回可读错误说明。
- **调用时机与易错点**：要先确认哪个对象和操作失败；旧错误文本不一定代表本次操作状态。

### `QTemporaryDir::isValid() / filePath(name)`

- **参数怎样填**：检查目录或生成其内部文件路径。
- **作用与返回结果**：返回 bool / QString。
- **调用时机与易错点**：临时目录必须活过所有文件操作，离开作用域会自动清理。

### `QJsonDocument::fromJson(bytes, error)`

- **参数怎样填**：UTF-8 JSON 字节与错误输出指针。
- **作用与返回结果**：返回文档对象；error 提供语法错误。
- **调用时机与易错点**：语法合法后仍需 isObject/isArray 和逐字段类型校验。

### `QJsonDocument::toJson(format)`

- **参数怎样填**：默认缩进或 Compact。
- **作用与返回结果**：返回序列化 QByteArray。
- **调用时机与易错点**：不自动验证你的业务规则或承诺旧版本兼容。

### `QJsonObject::value(key)`

- **参数怎样填**：字符串键。
- **作用与返回结果**：返回 QJsonValue，之后检查类型再读取。
- **调用时机与易错点**：缺失、null、空文本含义不同，不能全部默认成合法数据。

### `QWidget::setStyleSheet(qss)`

- **参数怎样填**：样式字符串。
- **作用与返回结果**：更新控件样式。
- **调用时机与易错点**：不是 HTML/CSS 浏览器；样式只能改变展示，不能完成业务状态迁移。

### `QTextDocument::setModified(false)`

- **参数怎样填**：bool 修改标记。
- **作用与返回结果**：标记文档与保存状态一致。
- **调用时机与易错点**：仅在真正读取或保存成功后清除；失败时保留原状态。
