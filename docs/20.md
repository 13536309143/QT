# 20 · 资源系统、QSS 与界面风格

## 资源打包
qrc 文件声明资源前缀和文件，rcc 将它们编进程序。示例使用 `:/lesson/readme.txt` 读取资源；Quick 里常见 qrc:/ URL。资源路径与磁盘绝对路径不同，也不随工作目录改变。资源是只读的，用户改过的配置应另存到可写目录。

## QSS 能做什么
Qt Style Sheets 可以设置颜色、边框、间距和部分控件外观，语法与 CSS 相似但能力不同。浏览器 CSS 的所有布局、动画和选择器不能原样套用。优先让布局负责几何，QSS 负责外观。
```css
QPushButton { padding: 8px 16px; border-radius: 6px; }
QPushButton:hover { background: #d9eee8; }
QLineEdit:focus { border: 1px solid #168477; }
```
示例把 theme.qss 也放进资源。修改后要重建才能看到变化。若运行时允许用户切换主题，可加载不同资源并设置 application 或窗口样式；注意局部样式的继承和覆盖关系。不要靠把所有字体都固定为很小像素来获得“精致”界面。

练习：给资源示例补充 hover、pressed、disabled 三种按钮状态；再新增一个带 objectName 的强调按钮，只对它应用样式。验收：禁用状态可辨认，键盘焦点仍可见，浅色背景上的文本有足够对比度。图标可使用自己制作或许可清楚的素材，并在仓库记录来源。

进阶：主题颜色抽成少量设计变量，通过生成 QSS 或统一调色板维护。QSS 复杂到难以预测时，先精简选择器并检查控件真实类名。

## 配套完整源码

在根工程构建本章目标：`12_resources`。以下是仓库内同一份文件，修改请到 examples 目录。

### assets.qrc

```xml
<RCC><qresource prefix="/lesson"><file>readme.txt</file><file>theme.qss</file></qresource></RCC>
```

### main.cpp

```cpp
#include <QtWidgets>
int main(int argc,char **argv) {
    QApplication app(argc,argv); QWidget w; auto *layout=new QVBoxLayout(&w);
    QFile text(":/lesson/readme.txt");
    if(!text.open(QIODevice::ReadOnly)) return 1;
    auto *label=new QLabel(QString::fromUtf8(text.readAll()),&w); layout->addWidget(label);
    QFile style(":/lesson/theme.qss");
    if(style.open(QIODevice::ReadOnly)) w.setStyleSheet(QString::fromUtf8(style.readAll()));
    layout->addWidget(new QPushButton(QStringLiteral("资源加载成功"),&w));
    w.resize(420,200); w.show();
    if(app.arguments().contains("--smoke")) QTimer::singleShot(150,&app,&QCoreApplication::quit);
    return app.exec();
}
```

### theme.qss

```css
QWidget { background: #eef5fa; color: #18354a; font-size: 16px; } QPushButton { padding: 12px; border: 1px solid #168477; border-radius: 6px; }
```

## 字符串、配置与文件：参数、结果与时机

### `QString::trimmed() / isEmpty()`

- **参数怎样填**：无参数。
- **作用与返回结果**：前者返回去首尾空白的新字符串；后者返回长度是否为 0。
- **调用时机与易错点**：trimmed 不原地修改；必须接收结果或继续链式调用。

### `QString::arg(value)`

- **参数怎样填**：占位符替换值，可链式调用。
- **作用与返回结果**：返回替换后的新 QString。
- **调用时机与易错点**：不是 SQL 参数绑定；需要控制小数格式时选择对应重载。

### `QString::toInt(ok, base)`

- **参数怎样填**：可传 bool 指针与进制，默认十进制。
- **作用与返回结果**：返回 int；通过 ok 区分真实 0 与解析失败。
- **调用时机与易错点**：不要直接相信失败时的默认数字，也要额外检查业务范围。

### `QString::toUtf8() / fromUtf8(bytes)`

- **参数怎样填**：前者无参数，后者接字节。
- **作用与返回结果**：在 Unicode 文本与 UTF-8 QByteArray 之间转换。
- **调用时机与易错点**：不要将半个多字节字符单独解码后拼接；协议先拆完整帧。

### `QString::size() / QByteArray::size()`

- **参数怎样填**：无参数。
- **作用与返回结果**：分别表示 UTF-16 代码单元数和字节数。
- **调用时机与易错点**：都不自动等于用户看到的字符数；接口限制必须写清单位。

### `QSettings::value(key, defaultValue)`

- **参数怎样填**：键名和键缺失时的默认 QVariant。
- **作用与返回结果**：返回 QVariant，可进一步检查转换结果。
- **调用时机与易错点**：默认值只处理缺失，不自动修复存在但内容损坏的值。

### `QSettings::setValue(key, value)`

- **参数怎样填**：键名与新值。
- **作用与返回结果**：记录配置更新，返回 void。
- **调用时机与易错点**：不是数据库事务或密码加密；多个字段的更新语义需自行设计。

### `QSettings::sync() / status()`

- **参数怎样填**：无参数。
- **作用与返回结果**：sync 同步存储；status 返回错误状态。
- **调用时机与易错点**：应在 sync 后检查状态并反馈保存失败，不能无条件显示成功。

### `QSettings::fileName()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回实际配置位置。
- **调用时机与易错点**：原生格式可能是注册表相关位置；本例选择显式 INI 便于观察。

### `QStandardPaths::writableLocation(type)`

- **参数怎样填**：如 AppConfigLocation 或 AppDataLocation。
- **作用与返回结果**：返回当前应用对应的可写位置 QString。
- **调用时机与易错点**：查询前设置应用标识，可能为空；返回目录不表示文件已创建。

### `QDir::mkpath(path)`

- **参数怎样填**：路径。
- **作用与返回结果**：返回 bool，递归创建目录或确认已存在。
- **调用时机与易错点**：失败需反馈，不能继续把写入错误解释成空数据。

### `QFile::open(mode)`

- **参数怎样填**：ReadOnly、WriteOnly 等打开模式。
- **作用与返回结果**：返回 bool，成功后才能 read/write。
- **调用时机与易错点**：文件不存在、权限、目录等都会导致失败，读取前检查。

### `QFile::readAll()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回剩余可读 QByteArray。
- **调用时机与易错点**：空内容与读取失败不同，还需 error()；大文件不要不设上限地一次全读。

### `QIODevice::write(bytes)`

- **参数怎样填**：要写入的 QByteArray。
- **作用与返回结果**：返回实际接受的字节数 qint64，-1 表示失败。
- **调用时机与易错点**：检查数值与目标长度；socket 接受不等于远端业务处理成功。

### `QSaveFile::commit()`

- **参数怎样填**：无参数。
- **作用与返回结果**：完成临时写入并替换目标，返回 bool。
- **调用时机与易错点**：只在写入完全成功后调用；失败不能更新文档路径或清除修改标记。

### `errorString()`

- **参数怎样填**：无参数；具体类如 QFile 或 socket。
- **作用与返回结果**：返回可读错误说明。
- **调用时机与易错点**：要先确认哪个对象和操作失败；旧错误文本不一定代表本次操作状态。

### `QTemporaryDir::isValid() / filePath(name)`

- **参数怎样填**：检查目录或生成其内部文件路径。
- **作用与返回结果**：返回 bool / QString。
- **调用时机与易错点**：临时目录必须活过所有文件操作，离开作用域会自动清理。

### `QJsonDocument::fromJson(bytes, error)`

- **参数怎样填**：UTF-8 JSON 字节与错误输出指针。
- **作用与返回结果**：返回文档对象；error 提供语法错误。
- **调用时机与易错点**：语法合法后仍需 isObject/isArray 和逐字段类型校验。

### `QJsonDocument::toJson(format)`

- **参数怎样填**：默认缩进或 Compact。
- **作用与返回结果**：返回序列化 QByteArray。
- **调用时机与易错点**：不自动验证你的业务规则或承诺旧版本兼容。

### `QJsonObject::value(key)`

- **参数怎样填**：字符串键。
- **作用与返回结果**：返回 QJsonValue，之后检查类型再读取。
- **调用时机与易错点**：缺失、null、空文本含义不同，不能全部默认成合法数据。

### `QWidget::setStyleSheet(qss)`

- **参数怎样填**：样式字符串。
- **作用与返回结果**：更新控件样式。
- **调用时机与易错点**：不是 HTML/CSS 浏览器；样式只能改变展示，不能完成业务状态迁移。

### `QTextDocument::setModified(false)`

- **参数怎样填**：bool 修改标记。
- **作用与返回结果**：标记文档与保存状态一致。
- **调用时机与易错点**：仅在真正读取或保存成功后清除；失败时保留原状态。
