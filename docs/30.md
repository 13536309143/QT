# 30 · TCP 实战：连接、拆包和有限缓冲

**前置**：第 24、29 章。**配套**：`16_tcp`。**目标**：不依赖外网和硬件，完成本机按行回显通信。

## 先写协议，再连接信号

本例协议：一条消息是最多 1024 字节的 UTF-8 文本，紧跟一个 LF 字节 `\n`；内容不能含 LF，不把 CRLF 自动解释为同一种结尾。空帧在拆帧层允许，但示例发送界面拒绝空输入。字节数限制不同于 QString 字符数，中文通常占多个 UTF-8 字节。

TCP 保证有序字节流，不保证一次 write 对应一次 readyRead。两次发送可能一起到达，一次发送也可能分几次收到；readAll 返回“当前可读数据”，没有“完整业务消息”的保证。

## 三个对象各司其职

QTcpServer 监听回环地址；服务端每条连接由独立 QTcpSocket 处理；客户端也有自己的 QTcpSocket。端口 0 让系统分配可用端口，再从 serverPort 读取，因此无需手动占固定端口。程序只接受本机连接，不是公开网络服务。

socket 通过 connected、readyRead、disconnected、errorOccurred 通知状态。GUI 线程中不调用 waitForConnected/waitForReadyRead 阻塞等待；监听和连接失败应反馈，不应直接当作“没有收到任何消息”。

## 拆帧器怎么工作

阅读 `examples/16_tcp/lineprotocol.h`：非换行字节先存入 buffer_，收到 LF 才输出完整行并清空缓存。一次输入包含两条完整消息就输出两条；只收到半条则留待下一次。只在取出完整帧后 fromUtf8，避免把多字节中文在中间切断后分别解码。

上限检查在继续追加之前进行，因此未闭合的超长帧会失败。窗口示例按 4096 字节读取，限制 socket 接收缓存和服务端待发送量，并限制日志行数。生产协议还要考虑连接总数、速率、握手和身份验证，本例不实现这些网络服务要求。

## 操作与错误路径

1. 运行 `scripts\run.cmd 16_tcp`，看到“已连接”后发送中文。
2. 阅读客户端 write 与服务端回写，标出请求和响应方向。
3. 在协议测试中将一行拆成两段输入，结果只在第二段出现。
4. 再把两行合成一次输入，应该得到两条结果。
5. 删除服务端的回写语句做故障实验，3 秒后客户端应超时并终止连接；完成后恢复源码。

write 成功只表示数据被本地接口接受，不等于对方业务已经处理。本例通过收到回显才结束等待；超时后会中止连接，重试需重新运行示例。--smoke 只检查启动，真实拆包与长度规则由单独测试验证。

验收：GUI 不被阻塞；中文可来回传输；半包、粘包和超长输入有明确行为。下一步可以设计带 requestId 的 JSON 行协议，但仍应先限制帧大小再解析。

参考：[QTcpSocket](https://doc.qt.io/qt-6.8/qtcpsocket.html)、[QTcpServer](https://doc.qt.io/qt-6.8/qtcpserver.html)。

## 配套完整源码

在根工程构建本章目标：`16_tcp`。运行 `scripts\run.cmd 16_tcp`。

### lineprotocol.h

```cpp
#pragma once
#include <QByteArray>
#include <QList>

// 无网络依赖的协议层：只负责拆帧，便于测试拆包、粘包与长度限制。
class LineProtocol {
public:
    static constexpr int MaxPayload = 1024;
    bool feed(const QByteArray &bytes, QList<QByteArray> &lines) {
        // 调用者按有界块读取，避免一次缓存任意大小的数据。
        for (char byte : bytes) {
            if (byte == '\n') {
                lines.append(buffer_);
                buffer_.clear();
            } else {
                if (buffer_.size() >= MaxPayload) { buffer_.clear(); return false; }
                buffer_.append(byte);
            }
        }
        return true;
    }
private:
    QByteArray buffer_;
};
```

### main.cpp

```cpp
#include <QtWidgets>
#include <QtNetwork>
#include <memory>
#include "lineprotocol.h"

int main(int argc, char **argv) {
    QApplication app(argc, argv);
    QWidget window;
    window.setWindowTitle(QStringLiteral("16 · 本机 TCP 按行通信"));
    auto *layout = new QVBoxLayout(&window);
    auto *input = new QLineEdit(QStringLiteral("你好，TCP"), &window);
    auto *send = new QPushButton(QStringLiteral("发送一行"), &window);
    auto *log = new QPlainTextEdit(&window);
    log->setReadOnly(true);
    log->document()->setMaximumBlockCount(200);
    layout->addWidget(input); layout->addWidget(send); layout->addWidget(log);
    QTcpServer server;
    QTcpSocket client;
    LineProtocol clientProtocol;
    bool pending = false;
    QTimer deadline;
    deadline.setSingleShot(true);
    deadline.setInterval(3000);
    send->setEnabled(false);
    QObject::connect(&server, &QTcpServer::newConnection, &window, [&] {
        while (server.hasPendingConnections()) {
            auto *peer = server.nextPendingConnection();
            peer->setReadBufferSize(4096);
            auto protocol = std::make_shared<LineProtocol>();
            QObject::connect(peer, &QTcpSocket::readyRead, peer, [peer, protocol] {
                QList<QByteArray> lines;
                while (peer->bytesAvailable() > 0) {
                    if (!protocol->feed(peer->read(4096), lines)) { peer->abort(); return; }
                    for (const auto &line : lines) {
                        if (peer->bytesToWrite() > 65536) { peer->abort(); return; }
                        peer->write(line + '\n');
                    }
                    lines.clear();
                }
            });
            QObject::connect(peer, &QTcpSocket::disconnected, peer, &QObject::deleteLater);
        }
    });
    QObject::connect(&client, &QTcpSocket::connected, &window, [&] {
        log->appendPlainText(QStringLiteral("已连接本机回显服务")); send->setEnabled(true);
    });
    QObject::connect(&client, &QTcpSocket::readyRead, &window, [&] {
        QList<QByteArray> lines;
        while (client.bytesAvailable() > 0) {
            if (!clientProtocol.feed(client.read(4096), lines)) { client.abort(); return; }
            for (const auto &line : lines) log->appendPlainText(QStringLiteral("收到：%1").arg(QString::fromUtf8(line)));
            if (!lines.isEmpty()) { pending = false; deadline.stop(); send->setEnabled(true); }
            lines.clear();
        }
    });
    QObject::connect(&client, &QTcpSocket::errorOccurred, &window, [&](QAbstractSocket::SocketError) {
        deadline.stop(); pending = false; send->setEnabled(false); log->appendPlainText(client.errorString());
    });
    QObject::connect(&client, &QTcpSocket::disconnected, &window, [&] { send->setEnabled(false); });
    QObject::connect(&deadline, &QTimer::timeout, &window, [&] {
        log->appendPlainText(QStringLiteral("响应超时，本次连接终止")); pending = false; client.abort(); send->setEnabled(false);
    });
    QObject::connect(send, &QPushButton::clicked, &window, [&] {
        const QByteArray bytes = input->text().toUtf8();
        if (pending || bytes.isEmpty() || bytes.size() > LineProtocol::MaxPayload || bytes.contains('\n')) {
            log->appendPlainText(QStringLiteral("请输入 1~1024 字节、不含换行的 UTF-8 文本")); return;
        }
        if (client.write(bytes + '\n') == -1) { log->appendPlainText(client.errorString()); return; }
        pending = true; send->setEnabled(false); deadline.start();
    });
    // 只监听回环地址，端口 0 由操作系统分配，不占用固定课程端口。
    if (!server.listen(QHostAddress::LocalHost, 0)) return 1;
    client.setReadBufferSize(4096);
    client.connectToHost(QHostAddress::LocalHost, server.serverPort());
    window.resize(620, 360); window.show();
    if (app.arguments().contains("--smoke")) QTimer::singleShot(300, &app, &QCoreApplication::quit);
    const int result = app.exec();
    // 在局部状态析构前断开窗口回调，再主动终止连接。
    QObject::disconnect(&client, nullptr, &window, nullptr);
    QObject::disconnect(&server, nullptr, &window, nullptr);
    QObject::disconnect(&deadline, nullptr, &window, nullptr);
    client.abort();
    server.close();
    return result;
}
```

## 线程、HTTP 与 TCP：参数、结果与时机

### `QThread::start() / isRunning()`

- **参数怎样填**：启动可指定优先级；查询无参数。
- **作用与返回结果**：启动线程 / 返回 bool。
- **调用时机与易错点**：线程开始不等于业务已经完成；重复点击前检查实际状态。

### `requestInterruption() / isInterruptionRequested()`

- **参数怎样填**：无参数。
- **作用与返回结果**：发协作取消请求 / 查询 bool。
- **调用时机与易错点**：请求不会强杀线程，工作代码需周期检查，阻塞操作还需有界超时。

### `QThread::quit() / wait()`

- **参数怎样填**：请求事件循环结束 / 可指定等待上限。
- **作用与返回结果**：quit 返回 void，wait 返回 bool。
- **调用时机与易错点**：quit 不会中断正在执行的长循环；GUI 上长时间 wait 会冻结界面。

### `QNetworkAccessManager::get(request)`

- **参数怎样填**：QNetworkRequest。
- **作用与返回结果**：返回 QNetworkReply 指针，网络异步继续。
- **调用时机与易错点**：调用返回不是请求完成；reply 生命周期与 finished/error 处理必须清楚。

### `QNetworkRequest::setTransferTimeout(ms)`

- **参数怎样填**：无数据传输超时毫秒数。
- **作用与返回结果**：设置传输超时策略。
- **调用时机与易错点**：不等同于所有情况下的总时限；课程另外设 singleShot 总时限。

### `QNetworkReply::attribute(code)`

- **参数怎样填**：如 HttpStatusCodeAttribute。
- **作用与返回结果**：返回 QVariant 状态信息。
- **调用时机与易错点**：无 HTTP 响应时可能没有状态码，不能把 0 当作正常 HTTP 状态。

### `QNetworkReply::error() / abort()`

- **参数怎样填**：查询或主动终止。
- **作用与返回结果**：返回错误枚举 / void。
- **调用时机与易错点**：abort 也会进入结束路径；恢复按钮和释放 reply 不应只写在成功分支。

### `QTcpServer::listen(address, port)`

- **参数怎样填**：监听地址和端口；0 请求系统分配。
- **作用与返回结果**：返回 bool；成功后用 serverPort 取实际端口。
- **调用时机与易错点**：本例只用 LocalHost；不要无意改为 Any 后把教学服务开放给局域网。

### `nextPendingConnection()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回待处理服务端 socket 指针。
- **调用时机与易错点**：在 newConnection 后处理；为每条连接保留独立解析器，并在断开后销毁。

### `QTcpSocket::connectToHost(address, port)`

- **参数怎样填**：地址与端口。
- **作用与返回结果**：启动异步连接，返回 void。
- **调用时机与易错点**：等待 connected 或 errorOccurred；不要在 GUI 中 waitForConnected 阻塞。

### `bytesAvailable() / read(maxSize)`

- **参数怎样填**：可读字节数查询或最大读取量。
- **作用与返回结果**：返回 qint64 / QByteArray。
- **调用时机与易错点**：一次读取不保证整帧，解析器必须保存尾部残留数据。

### `setReadBufferSize(bytes)`

- **参数怎样填**：最大接收缓冲字节数，0 有无限制语义。
- **作用与返回结果**：限制 socket 接收缓冲。
- **调用时机与易错点**：业务拆帧缓存、发送队列和日志也需分别设上限。

### `LineProtocol::feed(bytes, lines)`

- **参数怎样填**：自定义解析器；输入字节和输出完整行列表。
- **作用与返回结果**：返回 bool，false 表示超过帧上限。
- **调用时机与易错点**：按 LF 取帧，残留半帧保存在内部；false 时调用方终止连接，不把损坏数据当正常消息。

**阅读任务**：在本章源码中找到上述实际出现的调用，给每个返回值标出检查位置；同组的扩展接口用于对照，不要求在当前示例中全部出现。结合 [完整函数手册](API.md#async) 继续查阅。
