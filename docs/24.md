# 24 · 事件系统、定时器和自定义控件

## 事件与信号的区别
事件由事件循环分发到对象，例如鼠标、键盘、缩放和绘图。控件处理事件后可能发出更高层的信号，例如鼠标按下并释放后发 clicked。要响应命令优先连接信号，需要自定义底层交互时才重写事件处理函数。

重写 keyPressEvent 时，处理自己的按键后返回；未处理部分交给基类，以保留文本编辑和焦点行为。eventFilter 适合观察多个对象，但返回 true 会阻止目标继续处理该事件。过滤器用错很容易导致输入框不能输入。

## QTimer 的适用范围
QTimer 定期发 timeout，但不是精密实时计时器。GUI 忙时 timeout 会延迟；进度不能单靠“收到多少次定时器”推断真实时间。测量耗时用 QElapsedTimer，显示系统时间用 QDateTime。
```cpp
auto *timer = new QTimer(this);
connect(timer, &QTimer::timeout, this, [this] { update(); });
timer->start(50);
```
0 毫秒定时器可以把工作分片排队，但每片也必须足够短，且避免不断生产新工作使事件循环饥饿。定时器要在其所属线程启动和停止，线程需要事件循环。

练习：在自定义控件上处理空格键暂停动画；失去焦点后仍应允许 Tab 切到其他控件。验收：暂停停止数值变化，窗口遮挡后恢复仍能重绘，不能把所有事件都吃掉。

## 绘图、事件与计时：参数、结果与时机

### `QTimer::start(interval) / stop()`

- **参数怎样填**：间隔毫秒或停止无参数。
- **作用与返回结果**：开始或停止 timeout 通知。
- **调用时机与易错点**：定时器必须在所属线程正确使用；不保证实时频率，GUI 忙时会延迟。

### `QWidget::update()`

- **参数怎样填**：无参数或更新区域。
- **作用与返回结果**：安排稍后的重绘请求，返回 void。
- **调用时机与易错点**：不是立即递归调用 paintEvent；多个请求可能合并，适合状态变化后使用。

### `paintEvent(event)`

- **参数怎样填**：Qt 传入 QPaintEvent 指针。
- **作用与返回结果**：由 QWidget 绘制调度调用，返回 void。
- **调用时机与易错点**：不要在构造函数里直接调用来替代事件系统；普通控件 QPainter 在此创建。

### `QPainter(this)`

- **参数怎样填**：绘制设备，这里是当前 QWidget。
- **作用与返回结果**：开始当前绘制过程，局部对象析构后结束。
- **调用时机与易错点**：只能在允许绘制的时机操作该设备，不保留跨事件的活动 painter。

### `setRenderHint(QPainter::Antialiasing)`

- **参数怎样填**：渲染提示与可选 bool。
- **作用与返回结果**：开启边缘抗锯齿。
- **调用时机与易错点**：改善边缘，不改变几何计算或解决低分辨率图片问题。

### `translate(x,y) / scale(sx,sy)`

- **参数怎样填**：平移距离或缩放比例。
- **作用与返回结果**：改变后续绘图的坐标变换。
- **调用时机与易错点**：顺序会改变结果；常先移到窗口中心，再缩放逻辑画布。

### `setPen(pen) / setFont(font)`

- **参数怎样填**：画笔与字体对象。
- **作用与返回结果**：设置后续绘图状态。
- **调用时机与易错点**：状态会继续影响后面的命令，局部修改可配 save/restore。

### `drawArc(rect, start, span)`

- **参数怎样填**：外接矩形、起角和跨度。
- **作用与返回结果**：绘制圆弧；Qt 角度单位为 1/16 度。
- **调用时机与易错点**：不是弧度；正负跨度影响方向，示例乘 16 是有意转换。

### `drawText(rect, flags, text)`

- **参数怎样填**：区域、对齐/布局标志和文字。
- **作用与返回结果**：在区域内绘制文本。
- **调用时机与易错点**：区域过小会裁切；设置字体后重新检查布局和缩放。

### `eventFilter(watched, event)`

- **参数怎样填**：被观察对象与事件指针。
- **作用与返回结果**：返回 true 表示过滤掉本次事件。
- **调用时机与易错点**：只处理明确条件，其他交给基类；检查 type 后才能安全转换具体事件类型。

### `QElapsedTimer::start() / elapsed()`

- **参数怎样填**：开始无参数，读取无参数。
- **作用与返回结果**：记录起点与经过的毫秒数。
- **调用时机与易错点**：用于测持续时间；日历时间与时区使用 QDateTime，不能混用。
