# 52 · OpenGL 扩展实操：矩阵、相机、纹理与深度

本章是在 17_opengl 上逐步修改的实验，片段需加入类成员、相应头文件并修改 shader，不是另一份可直接双击的完整程序。每一步保持可运行后再继续。

## 一、从直接坐标变成矩阵

顶点 shader 增加 `uniform mat4 mvp;`，将位置表达式改为 `mvp * vec4(position,0.0,1.0)`。uniform 是一次绘制中共享的参数，不是每个顶点都在 VBO 中再复制一个矩阵。

paintGL 中建立投影、观察与物体变换：

```cpp
QMatrix4x4 model, view, projection;
model.rotate(angle_, 0.0f, 0.0f, 1.0f);
view.lookAt(QVector3D(0,0,3), QVector3D(0,0,0), QVector3D(0,1,0));
const float aspect = float(width()) / float(qMax(1, height()));
projection.perspective(45.0f, aspect, 0.1f, 100.0f);
program_->bind();
program_->setUniformValue("mvp", projection * view * model);
```

angle_ 是你新增的 float 成员。QMatrix4x4 默认单位矩阵；rotate 接角度与轴；lookAt 接眼睛、目标、向上方向；perspective 的第一个参数是垂直视场角，near 必须大于 0，far 大于 near。setUniformValue 前绑定正确 program，名字与 GLSL 完全一致。

uniformLocation 返回 -1 可能表示拼写错误，也可能是该 uniform 被优化掉；不能把 -1 当成合法位置静默忽略。不要盲目用 transpose 修复矩阵问题，先确认列向量约定、乘法次序和数据上传接口。

## 二、相机移动为何像物体反着移动

view 是世界到观察空间的变换。相机向右移动，静止物体在画面上看起来向左移动，这不是坐标计算错。先固定 model 只改 view，再固定 view 只改 model，分别验证。鼠标输入先修改相机状态，再 update；GL 调用仍放 paintGL。

## 三、把颜色属性换成纹理坐标

纹理坐标一般为 u,v 两个 float。若记录变成 x,y,u,v，则 stride 为 4*sizeof(float)，第二条属性分量数为 2，offset 为 2*sizeof(float)。同时修改 shader 的输入类型、输出类型和片元 sampler，不能只改 CPU 数组。

```glsl
// 片元着色器的核心；仍需 #version 与匹配的顶点阶段
in vec2 uv;
uniform sampler2D imageTexture;
out vec4 fragmentColor;
void main() { fragmentColor = texture(imageTexture, uv); }
```

在 initializeGL 中加载 QImage，先 isNull 检查，再建立 QOpenGLTexture。bind(0) 把纹理绑定到纹理单元 0，setUniformValue("imageTexture",0) 传的是单元编号，不是纹理 handle。构造、上传和清理都需当前上下文，纹理对象也要加入 cleanup。

QImage 的行方向与纹理坐标约定可能导致上下颠倒；可以调整 uv 或使用镜像图像，但不要同时做两次翻转。图片格式、alpha、sRGB 与线性空间是不同问题；先用四角颜色不同的测试图判断方向，再处理真实照片。

## 四、深度与透明不是同一开关

已有深度附件后，glEnable(GL_DEPTH_TEST) 才启用深度比较；每帧清 GL_DEPTH_BUFFER_BIT，才不会让旧帧深度阻挡新内容。near/far 范围过大或面几乎共面会引发精度问题，先改善投影范围，再考虑更复杂方法。

常见普通 alpha 混合使用 GL_SRC_ALPHA 与 GL_ONE_MINUS_SRC_ALPHA，但还需启用 GL_BLEND 并考虑绘制顺序。透明对象常需要特殊排序和深度写入策略；单凭给 shader 输出 alpha=0.5 不会自动得到正确透明场景。

## 五、按顺序验收

先显示一个旋转三角形；再显示贴有四角测试图的矩形；最后绘制两个不同深度的面，交换 draw 顺序后观察遮挡。每步都记录 shader、stride、uniform、状态分别改了什么。

只有在前面四项正确时才加入模型加载、灯光与法线。法线在非均匀缩放后不能总按位置矩阵直接变换；这是下一轮 3D 项目的独立主题，不应在入门时用一句“加光照即可”跳过。
