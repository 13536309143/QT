# 07 · 第一个窗口与事件循环

## 阅读 01_hello
首先包含 QApplication 和 QLabel。创建 QApplication 后再创建控件，因为 GUI 对象需要应用级初始化。QLabel 是显示文本的控件；不给 QWidget 父对象，它就可以成为顶层窗口。`resize` 设置初始尺寸；`show` 使窗口可见；`app.exec()` 开始分发操作系统事件。

这不是从上到下执行完就结束的脚本。事件循环不断等待鼠标、键盘、定时器和重绘请求，并分派给相关对象。窗口关闭后，在默认配置下最后一个顶层窗口关闭会让应用退出。`show()` 后还没有进入循环时，窗口可能尚未来得及真正绘制。

## 操作步骤
1. 运行 `scripts\run.cmd 01_hello`，观察窗口标题、居中文字和默认尺寸。
2. 把文本改为两行自我介绍，重新构建目标后运行。
3. 去掉 setAlignment，观察默认对齐方式；恢复后将尺寸减小。
4. 在 exec 前加入日志，关闭窗口后在 exec 返回处再打印日志，理解程序停留在哪里。

## 不要阻塞 GUI 线程
若在点击处理里运行十秒循环，鼠标响应、重绘和定时器都会被拖住。插入 `processEvents()` 可能引入嵌套调用和对象提前销毁，不应成为耗时任务的常规解决方案。短任务用定时器分批，长任务交给后台线程。

程序还支持 `--smoke` 参数，短暂进入事件循环后自动退出，供自动检查启动使用。这只能证明程序能初始化，不能替代实际点击、输入和缩放的交互验收。

练习：增加最小尺寸和窗口标题。验收：窗口能缩放，文本没有固定位置溢出；能说明 QApplication 与 QWidget 的析构顺序为何合理。

## 配套完整源码

在根工程构建本章目标：`01_hello`。以下是仓库内同一份文件，修改请到 examples 目录。

### main.cpp

```cpp
#include <QApplication>
#include <QLabel>
#include <QTimer>
int main(int argc, char *argv[]) {
    QApplication app(argc, argv); // QApplication 必须先于任何 QWidget 创建
    QLabel label(QStringLiteral("你好，Qt！\n缩放窗口试试看。"));
    label.setAlignment(Qt::AlignCenter);
    label.resize(480, 260);
    label.setWindowTitle(QStringLiteral("01 · 第一个窗口"));
    label.show();
    if (app.arguments().contains("--smoke")) QTimer::singleShot(150, &app, &QCoreApplication::quit);
    return app.exec(); // 进入事件循环，关闭最后一个窗口后退出
}
```

## 窗口与应用：参数、结果与时机

### `QApplication(argc, argv)`

- **参数怎样填**：接收 main 的参数；argc 按引用传递，因此不能传临时值。
- **作用与返回结果**：创建 Widgets 应用对象，建立 GUI 所需环境；不是显示一个窗口。
- **调用时机与易错点**：一个进程通常只建一个应用对象，而且要早于 QWidget 构造，晚于窗口析构。

### `QWidget(parent)`

- **参数怎样填**：parent 是父控件，可为 nullptr。
- **作用与返回结果**：创建控件；没有父控件时通常是顶层窗口。
- **调用时机与易错点**：父控件影响可视层级与销毁责任；构造不会自动 show。

### `QLabel(text, parent)`

- **参数怎样填**：text 为待显示 QString；parent 为所有者。
- **作用与返回结果**：创建文本或图片展示控件，本例显示文字。
- **调用时机与易错点**：标签不负责业务数据校验；展示字符串不应作为唯一业务状态。

### `resize(width, height)`

- **参数怎样填**：两个 int 表示控件逻辑尺寸。
- **作用与返回结果**：请求调整尺寸，返回 void；布局和尺寸约束可能影响最终大小。
- **调用时机与易错点**：不是物理像素保证，也不代表禁止用户再次缩放。

### `setWindowTitle(title)`

- **参数怎样填**：QString 窗口标题。
- **作用与返回结果**：改变顶层窗口标题，返回 void。
- **调用时机与易错点**：子控件设置标题不一定产生可见顶层标题。

### `setAlignment(flags)`

- **参数怎样填**：如 Qt::AlignCenter，可用按位或组合水平与垂直方向。
- **作用与返回结果**：改变 QLabel 内容对齐。
- **调用时机与易错点**：不是移动控件本身；控件位置由布局决定。

### `show()`

- **参数怎样填**：无参数。
- **作用与返回结果**：请求显示窗口并安排平台事件；返回 void。
- **调用时机与易错点**：返回时不保证首帧已经绘制，更不代表渲染验证通过。

### `exec()`

- **参数怎样填**：应用对象无参数版本。
- **作用与返回结果**：进入事件循环，直到 quit/exit；返回 int 退出码。
- **调用时机与易错点**：不是每次点击都调用一次，GUI 线程中的长任务会阻止循环分发事件。

### `arguments()`

- **参数怎样填**：无参数。
- **作用与返回结果**：返回 QStringList 命令行参数，包含程序名。
- **调用时机与易错点**：本课程用 contains("--smoke") 判断启动检查模式，不能把它当业务界面输入。

### `QTimer::singleShot(ms, context, functor)`

- **参数怎样填**：毫秒延迟、生命周期上下文和回调。
- **作用与返回结果**：安排一次回调；返回 void。
- **调用时机与易错点**：延迟不是精密截止时间；上下文销毁后不执行该回调。

### `QCoreApplication::quit()`

- **参数怎样填**：无参数。
- **作用与返回结果**：请求事件循环以正常退出方式结束。
- **调用时机与易错点**：不会自动中断正卡住的用户代码；重要数据仍要走保存与退出策略。
