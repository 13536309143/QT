# 00 · 学习地图：从零到独立开发

## 这套课程怎么用
这是一套中文离线课程，面向想用 C++ 开发桌面软件的学习者。主线采用 **Qt 6.8.3、C++17、CMake、Windows x64 + MSVC 2022**。固定版本是为了方便重现课堂结果，不代表它是最新版本。软件框架、编辑器、编译器是三个不同的东西：Qt 提供类库，Qt Creator 提供开发界面，MSVC 把代码编译为机器指令。安装了编辑器并不等于安装了编译器。

每章按“概念 → 阅读源码 → 动手修改 → 验收”学习。不要只看窗口是否出现；要能说出输入在哪里验证、对象由谁销毁、失败如何反馈、文件保存在哪里。建议每天 60~90 分钟，先运行原例，再改一个功能，最后写三句话学习记录。

## 入门者容易误解的事
Qt 不是一种新语言。`signals`、`slots`、`Q_OBJECT` 是 Qt 构建工具配合 C++ 实现的机制。Widgets 和 Quick 是两条界面路线，本课程先用 Widgets 训练 C++ 和桌面交互，再学习 QML 的声明式界面。你不必同时精通所有模块；本课程覆盖常用主干，串口、音视频、3D 等方向放在拓展章节，按项目需求选学。

## 第一项练习
建立学习日志，记录电脑上的 Qt 版本、编译器、构建目录和首个错误。验收：不借助记忆，能从 README 的指令打开并运行第一个示例。



## 初学者补充路线

刚接触 C++ 时先读 [第 01 章预备课](01.md)，再读 [第 02 章工具入门](02.md)，然后按目录的八个阶段前进。全书按学习顺序连续编号为 00～66，章节文件名、页面标题、目录与翻页顺序一致。

每次学习完成四件事：运行原例；用自己的话解释输入、输出与对象寿命；修改一个功能；验证正常、边界和失败路径。第一周不要求学习线程、数据库和 QML。

### 前七次学习安排

| 次数 | 阅读与操作 | 完成标准 |
|---|---|---|

进度可按个人基础拆成多天。遇到阻碍时使用 [答疑与术语表](48.md)，每周用一个独立重写的小功能检查理解程度。
